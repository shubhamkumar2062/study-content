# Last-night revision sheet

If you have only an hour, practise these labelled diagrams once each: **heart (interior with valves)**, **nephron**, **lung and bronchial tree**, **eyeball**, **ear**, **synovial joint**, **long bone**, **skin** and **brain (lobes and functional areas)**. Then read the tables below.

**Terms and tissues**

| Item | Key fact |
| --- | --- |
| Planes | Sagittal → right/left; coronal → front/back; transverse → upper/lower |
| Movements | Flexion/extension, abduction/adduction, rotation, supination (palm forward/up), pronation, inversion/eversion, plantar/dorsiflexion, circumduction |
| Epithelium | Simple squamous — alveoli; pseudostratified ciliated — trachea; transitional — bladder; keratinised stratified — skin |
| Cartilage | Hyaline — joints, trachea; fibro — discs, symphysis, menisci; elastic — pinna, epiglottis |
| Glands | Holocrine — sebaceous; apocrine — axillary sweat, breast; merocrine — salivary |

**Systems at a glance**

| System | Must-know facts |
| --- | --- |
| Respiratory | Trachea C6–T4/5, 16–20 C rings; right bronchus short, wide, vertical; right lung 3 lobes, left 2 + cardiac notch; type II cells make surfactant; diaphragm = phrenic C3–C5, openings T8 (IVC), T10 (oesophagus), T12 (aorta) |
| Digestive | Wall: mucosa, submucosa, muscularis, serosa; stomach has an oblique layer, parietal cells (HCl, intrinsic factor); duodenum — ampulla of Vater; ileum — Peyer's patches; colon — taeniae, haustra; liver lobule — central vein, portal triad; cystic + common hepatic = common bile duct |
| Circulatory | Apex — left 5th space, midclavicular line; pericardium, myocardium, endocardium; tricuspid right, mitral left; coronary arteries from ascending aorta; SA node → AV node → bundle of His → Purkinje; median cubital vein for blood samples |
| Lymphatic | Thoracic duct from cisterna chyli → left venous angle; spleen in left hypochondrium; thymus shrinks after puberty |
| Endocrine | Pituitary in sella turcica; thyroid lobes + isthmus (rings 2–4); 4 parathyroids; adrenal cortex zones G-F-R (salt, sugar, sex), medulla adrenaline; islets — beta cells insulin |
| Sense organs | Epidermis 5 layers, no vessels; eye coats: fibrous, vascular (uvea), nervous (retina); fovea sharpest; optic disc blind spot; ossicles malleus–incus–stapes; organ of Corti in cochlea; taste VII and IX |
| Skeletal | 206 bones (80 axial, 126 appendicular); long bone parts; growth in length at epiphyseal plate; vertebrae 7-12-5-5-4; joints fibrous / cartilaginous / synovial; knee — menisci, cruciates |
| Muscular | Deltoid (axillary nerve) abducts arm; ventrogluteal = gluteus medius; dorsogluteal risks sciatic nerve; vastus lateralis for infants |
| Renal | Kidneys T12–L3, retroperitoneal, right lower; nephron = glomerulus + Bowman's capsule + PCT + loop + DCT → collecting duct; ureter 25–30 cm; trigone; urethra F 4 cm, M 18–20 cm |
| Reproductive | Seminiferous tubules (sperm), Leydig cells (testosterone); sperm path testis → epididymis → vas → ejaculatory duct → urethra; uterus anteverted, anteflexed; fertilisation in ampulla; breast 15–20 lobes, Cooper's ligaments, axillary nodes |
| Nervous | Meninges dura–arachnoid–pia; medulla = vital centres; precentral motor, postcentral sensory; Broca's (speech) and Wernicke's (understanding) usually left; cord ends L1–L2; 31 spinal nerve pairs; sympathetic T1–L2, parasympathetic cranial + S2–S4 |

**CSF pathway (write it as a chain)**

```text
Choroid plexus → lateral ventricles → foramina of Monro → 3rd ventricle
→ cerebral aqueduct → 4th ventricle → foramina of Magendie and Luschka
→ subarachnoid space → arachnoid villi → superior sagittal sinus
```

**Cranial nerves in one line**: I olfactory, II optic, III oculomotor, IV trochlear, V trigeminal, VI abducens, VII facial, VIII vestibulocochlear, IX glossopharyngeal, X vagus, XI accessory, XII hypoglossal.

**Nursing links to quote**: IM sites and nerves to avoid; IV veins of the hand and forearm; lumbar puncture at L3–L4/L4–L5; chest compressions on the lower half of the sternum; catheter insertion (short female urethra); ear drops — pull pinna up and back in adults; breast self-examination including the axillary tail; opposite-side weakness after stroke.

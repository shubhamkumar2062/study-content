## Must-know comparisons

### Marasmus vs Kwashiorkor

| Feature | Marasmus | Kwashiorkor |
| --- | --- | --- |
| Weight | < 60% of median | 60–80% of median |
| Oedema | Absent | Present (bilateral pitting) |
| Appearance | Severe wasting, skin and bone, old-man face | Oedema, skin lesions, pot belly |
| Hair | Sparse, dry | Discoloured (flag sign), easily plucked |
| Liver | Fatty liver (possible) | Hepatomegaly (fatty infiltration) |
| Mood | Alert, hungry | Apathetic, anorexic |
| Cause | Calories AND protein deficit | Mainly protein deficit |

### Incidence vs Prevalence

| Feature | Incidence | Prevalence |
| --- | --- | --- |
| Definition | New cases over a time period | All existing cases at one time |
| Use | Acute diseases; risk; aetiology studies | Chronic diseases; service planning |
| Formula | New cases ÷ Population at risk × constant | All cases ÷ Total population × constant |
| Relationship | Prevalence ≈ Incidence × Duration | — |

### Sensitivity vs Specificity

| Feature | Sensitivity | Specificity |
| --- | --- | --- |
| Formula | TP ÷ (TP + FN) | TN ÷ (TN + FP) |
| Meaning | Correctly identifies true positives | Correctly identifies true negatives |
| Use when | Missing a case is dangerous (high-stakes disease) | False positives cause harm (unnecessary treatment) |
| High means | Few false negatives | Few false positives |

### Quarantine vs Isolation

| Feature | Quarantine | Isolation |
| --- | --- | --- |
| Who | Well persons exposed to a communicable disease | Persons with confirmed infectious disease |
| Duration | One incubation period | Until no longer communicable |
| Goal | Prevent exposure of others if person develops disease | Prevent spread from known cases |

### Case-Control vs Cohort Study

| Feature | Case-Control | Cohort |
| --- | --- | --- |
| Direction | Retrospective (back in time from outcome) | Prospective (forward in time from exposure) |
| Start with | Cases and controls | Exposed and unexposed groups |
| Measure | Odds ratio (OR) | Relative risk (RR) |
| Good for | Rare diseases | Incidence; multiple outcomes |
| Main bias | Recall bias | Loss to follow-up |

## Sequences to draw from memory

### Outbreak investigation steps

```text
1. Verify diagnosis
2. Confirm it is an outbreak (numbers above baseline)
3. Define a case definition
4. Count all cases
5. Describe: person, place, time (epidemic curve)
6. Develop hypotheses
7. Test hypotheses (analytical study)
8. Implement control measures
9. Communicate findings
10. Write a report
```

### Water treatment steps

```text
Collection → Screening (remove large debris) → Sedimentation
→ Coagulation-flocculation → Sand filtration
→ Disinfection (chlorination, residual 0.2–0.5 mg/L at consumer end)
→ Storage and distribution
```

### Bag technique (home visit)

```text
On entering home:
1. Lay clean paper on a surface (clean zone).
2. Place bag on clean paper.
3. Wash hands (alcohol gel or soap and water).
4. Take out only needed items.
5. Perform procedure.
6. Place used items in a separate waste bag (dirty zone).
7. Wash hands again.
8. Repack bag (clean items only inside).
Never mix clean and dirty zones.
```

## Exam reminder

- Section A (20 marks): one mark per question — use the elimination method; know acronyms (NTEP, NVBDCP, NACP, NPCDCS, ICDS); know standard rates and formulas.
- Section B (20 marks): write 2 of 3 essays; use the standard 5-part structure for any communicable disease (agent, transmission, features, diagnosis, management); always end with nursing care and community role.
- Section C (35 marks): 7 of 9 short answers; choose what you know most; for a 5-mark answer use 5 clear points; epidemiology formulas with examples and national programmes with key activities are reliable short-answer topics.
- For any community programme question: name the programme, year launched or key regulation, target group, key intervention, and implementing agency.
- For any epidemiology question involving a formula: state the formula explicitly before substituting values; write the numerator and denominator.

# Last-night revision sheet

Mental Health Nursing I is a 75-mark paper. If you have one hour, work through the tables below in order, then run the Quick MCQ test.

---

## Key terms

| Term | One-line meaning |
| --- | --- |
| Mental health | State of well-being; realise abilities, cope with stress, work, contribute |
| Mental illness | Clinically significant disturbance of thinking, mood, perception or behaviour with distress/impaired function |
| Stigma | Stereotype + prejudice + discrimination directed at a person because of their mental illness |
| Therapeutic relationship | Purposeful, professional, goal-directed relationship between nurse and patient (Peplau) |
| Transference | Patient projects feelings about past relationships onto the nurse |
| Counter-transference | Feelings the patient arouses in the nurse |
| MSE | Mental Status Examination — systematic description of the patient's mental functioning at the time of interview |
| Hallucination | False sensory perception with no external stimulus |
| Illusion | Misinterpretation of a real external stimulus |
| Delusion | Fixed, false, unshakeable belief not shared by the culture, resistant to evidence |
| Mood | Patient's subjective sustained feeling state |
| Affect | Examiner's objective observation of emotional expression |
| Insight | Degree to which the patient understands they have an illness needing treatment |
| Psychosis | Loss of contact with reality — hallucinations and/or delusions |
| Neurosis | Mental disorder without break with reality; awareness of illness; anxiety-based |

## MSE domains (A B S M A T P C I J)

| Domain | Key terms to know |
| --- | --- |
| **A**ppearance | Dress, hygiene, eye contact, posture, nutrition |
| **B**ehaviour | Retardation, agitation, catatonia, waxy flexibility, echopraxia |
| **S**peech | Rate, volume, tone; pressured, poverty, mutism, echolalia |
| **M**ood / **A**ffect | Mood = subjective; Affect = objective; flat, blunted, labile, incongruent, appropriate |
| **T**hought form | Flight of ideas, loosening of associations, thought blocking, circumstantiality, tangentiality |
| **T**hought content | Delusions (types); obsessions; phobias; suicidal/homicidal ideation |
| **P**erception | Hallucinations (auditory most common in schizophrenia), illusions, derealization, depersonalisation |
| **C**ognition | Consciousness, orientation (time/place/person), attention, memory (immediate/recent/remote), abstraction |
| **I**nsight | Grade 1 (complete denial) to Grade 6 (full insight) |
| **J**udgement | Response to practical dilemmas; intact vs impaired |

## Therapeutic vs non-therapeutic communication

| Therapeutic | Non-therapeutic |
| --- | --- |
| Active listening | False reassurance ("don't worry") |
| Open-ended questions | Advice-giving ("you should …") |
| Reflection of feeling | Agreeing with delusions |
| Restatement | Changing the subject |
| Clarification | Excessive questioning / interrogation |
| Focusing | Moralising / judging |
| Sharing observations | Closed yes/no questions only |
| Summarising | Belittling / minimising |
| Offering self | Using medical jargon |

## Peplau's phases of the nurse-patient relationship

```text
  ORIENTATION → IDENTIFICATION → EXPLOITATION → RESOLUTION
  Trust built     Patient uses     Full use of     Goals met;
  Assessment      nurse as helper  services        Relationship
  Roles explained                  Problem-solving  ends positively
```

Peplau's six nurse roles: Stranger → Resource person → Teacher → Leader → Surrogate → Counsellor.

## Drug class comparison: psychiatry

| Class | Key drugs | Main use | Critical nursing point |
| --- | --- | --- | --- |
| Typical antipsychotic | Haloperidol, chlorpromazine | Psychosis | High EPS risk; monitor for dystonia, pseudo-parkinsonism, akathisia, tardive dyskinesia |
| Atypical antipsychotic | Olanzapine, risperidone, quetiapine, aripiprazole | Psychosis, bipolar | Metabolic syndrome (weight, glucose, lipids); less EPS |
| Clozapine | Clozapine | Treatment-resistant schizophrenia | Weekly WBC (agranulocytosis 1–2%); mandatory monitoring |
| SSRI | Fluoxetine, sertraline, escitalopram | Depression, anxiety, OCD | 2–4 weeks onset; monitor suicidal ideation early; serotonin syndrome risk |
| TCA | Amitriptyline, imipramine, clomipramine | Depression, OCD, pain | Dangerous in overdose (cardiac); anticholinergic side effects |
| MAOI | Phenelzine | Depression | Tyramine-rich food interaction → hypertensive crisis |
| Lithium | Lithium carbonate | Bipolar prevention | Narrow window 0.6–1.0 mEq/L; dehydration raises levels; monitor thyroid, kidney |
| Valproate | Sodium valproate | Mania, bipolar | LFT; teratogenic (avoid in pregnancy); thrombocytopenia |
| Benzodiazepine | Diazepam, lorazepam | Anxiety, acute agitation | Short-term only; dependence; CNS depression; never abrupt stop |
| Buspirone | Buspirone | GAD | No dependence; takes 2–4 weeks |

## Extrapyramidal side effects (EPS) timeline

```text
  Hours–days     Days–weeks           Days–weeks      Months–years
  ACUTE DYSTONIA → PSEUDO-PARKINSONISM → AKATHISIA → TARDIVE DYSKINESIA
  (muscle spasm,   (tremor, rigidity,    (restless      (involuntary face/
   neck, eyes,      bradykinesia)         urge to move)  limb movements;
   tongue)                                               may be irreversible)
  TREAT: anticholinergic (benztropine/procyclidine)
```

**NMS (neuroleptic malignant syndrome):** hyperthermia + rigidity + altered consciousness + autonomic instability. STOP drug immediately — medical emergency.

## Lithium toxicity levels

| Level | Serum lithium | Features |
| --- | --- | --- |
| Therapeutic (maintenance) | 0.6–1.0 mEq/L | — |
| Mild toxicity | 1.0–1.5 mEq/L | Nausea, vomiting, diarrhoea, tremor, thirst, polyuria |
| Moderate toxicity | 1.5–2.0 mEq/L | Coarse tremor, confusion, drowsiness, ataxia |
| Severe toxicity | >2.0 mEq/L | Seizures, cardiac arrhythmia, coma |

**Action:** withhold dose, IV fluids, report at once; haemodialysis if severe.

## Schizophrenia: positive vs negative symptoms

| Positive (added) | Negative (taken away) |
| --- | --- |
| Hallucinations (auditory: voices) | Flat/blunted affect |
| Delusions (persecutory, passivity, grandiose) | Alogia (poverty of speech) |
| Disorganised speech | Avolition (lack of motivation) |
| Disorganised behaviour / catatonia | Anhedonia (inability to feel pleasure) |
| | Asociality (social withdrawal) |
| Treat well with antipsychotics | Difficult to treat; most responsible for disability |

Schneider's first-rank symptoms: thought insertion/withdrawal/broadcasting, passivity, delusional perception, third-person auditory hallucinations.

## Mood disorders quick comparison

| Feature | Depression | Mania |
| --- | --- | --- |
| Mood | Low, hopeless, sad | Elevated, euphoric or irritable |
| Activity | Psychomotor retardation | Psychomotor agitation |
| Sleep | Insomnia (early morning waking) or hypersomnia | Decreased need for sleep (3 h feels enough) |
| Speech | Poverty of speech, slow | Pressured, rapid, loud |
| Thinking | Negative (Beck's triad) | Grandiose, flight of ideas |
| Appetite | Decreased (usually) | May not stop to eat |
| Insight | Usually partial; hopelessness | Usually poor; denies illness |
| Risk | Suicide | Reckless behaviour, self-harm |

## Suicide risk — high vs low features

| High risk | Low risk |
| --- | --- |
| Previous attempt | First presentation |
| Specific lethal plan | No specific plan |
| Access to means | No access to means |
| Male sex, older age | Female sex, younger age |
| Social isolation | Strong social support |
| Hopelessness | Ambivalence, reasons for living |
| Alcohol/drug use | No substance use |
| Active intent | Passive ideation only |

Hopelessness is a stronger predictor than depression severity. Always ask directly about suicidal ideation.

## Anxiety levels (Peplau) in brief

| Level | Key feature | Nurse's response |
| --- | --- | --- |
| Mild (+) | Alert, learning enhanced | Use it |
| Moderate (++) | Narrowed focus, some impairment | Redirect, stay calm |
| Severe (+++) | Focus on one detail only, physical symptoms | Direct instructions, stay with patient |
| Panic (++++) | Disorganised, terror, cannot function | Never leave alone; medication if ordered |

## ECT nursing care in brief

| Phase | Key actions |
| --- | --- |
| Before | Informed consent; NBM 6–8 h; remove metal, dentures, nail polish; baseline vitals; empty bladder; pre-medications |
| During | Assist anaesthetist; observe and time seizure; monitor SpO2 and ECG |
| After | Recovery (lateral) position; maintain airway; monitor vitals; reorient gently; give analgesia for headache; NBM until gag reflex returns; never leave alone |

Main side effect: short-term memory loss (usually resolves). Fastest treatment for severe depression with suicidal risk or refusal to eat.

## OCD vs other thought disorders

| Feature | OCD | Schizophrenia |
| --- | --- | --- |
| Ego-dystonic thoughts? | Yes — patient knows obsessions are own and excessive | Thought insertion — patient believes thoughts come from outside |
| Insight into thoughts? | Yes | Often absent |
| Treatment | ERP + SSRI (clomipramine) | Antipsychotic |
| Compulsions | Yes | No |

## PTSD four clusters (remember as RE AN H)

```text
  RE-experiencing:  Flashbacks, nightmares, psychological and physical reactivity
  Avoidance:        Avoiding thoughts, feelings, reminders of trauma
  Negative changes: Distorted beliefs, negative emotions, detachment
  Hyperarousal:     Hypervigilance, exaggerated startle, sleep disturbance, irritability
```

Treatment: trauma-focused CBT or EMDR; SSRI.

## MHCA 2017 — key provisions for the exam

- Right to access mental health care from government facilities.
- Right to community living; involuntary hospitalisation only by magistrate's order.
- Right to make an advance directive; right to nominate a representative.
- Confidentiality is mandatory.
- Chaining of patients is prohibited.
- ECT without anaesthesia is prohibited.
- Sterilisation as a treatment for mental illness is prohibited.
- Mental Health Review Boards oversee rights compliance.

# Last-night revision sheet

## Section A: Applied Microbiology

| Topic | Key facts |
| --- | --- |
| History | Leeuwenhoek — first saw microbes; Jenner — smallpox vaccine (1796); Semmelweis — hand washing; Pasteur — germ theory, pasteurization, rabies vaccine; Lister — carbolic acid, antiseptic surgery; Koch — TB, cholera, postulates; Gram — stain (1884); Fleming — penicillin (1928) |
| Chain of infection | Agent → reservoir → portal of exit → mode of transmission → portal of entry → susceptible host |
| Prokaryote | No nucleus, 70S ribosomes, binary fission; viruses are not cells |
| Bacterial cell | Capsule (resists phagocytosis), wall (peptidoglycan), membrane, nucleoid, plasmid (resistance genes), flagella (motility), pili (attachment), spores (*Bacillus*, *Clostridium*) |
| Gram reaction | Positive: thick wall, purple. Negative: thin wall + outer membrane (endotoxin), pink |
| Shapes | Cocci in clusters — staphylococci; chains — streptococci; diplococci — pneumococcus, *Neisseria*; comma — *Vibrio*; spiral — *Treponema*, *Leptospira* |
| Growth curve | Lag → log → stationary → decline; pathogens are mesophiles, 37 °C |
| Oxygen | Obligate aerobe — *Pseudomonas*, *M. tuberculosis*; obligate anaerobe — *Clostridium*, *Bacteroides*; facultative — *E. coli*, *Staphylococcus* |
| Gram stain | Crystal violet → iodine → acetone/alcohol → safranin |
| ZN stain | Hot carbol fuchsin → 20% H2SO4 → methylene blue; AFB red |
| Special stains | India ink (capsule, *Cryptococcus*); Albert's (diphtheria granules); spore stain; LPCB (fungal culture); KOH mount (skin, hair, nail) |
| Media | Enriched — blood, chocolate agar; enrichment (liquid) — selenite F, alkaline peptone water; selective — LJ (TB), TCBS (cholera); differential — MacConkey (pink lactose fermenters); transport — Stuart's, Amies, Cary–Blair, VTM; anaerobic — Robertson's cooked meat |
| Pure culture | Streak plate (routine), pour plate and spread plate (counts), tube dilution |
| Anaerobic culture | McIntosh–Fildes jar with GasPak; methylene blue indicator |
| Key bacteria | *S. aureus* — boils, wound infection, MRSA; *S. pyogenes* — sore throat → rheumatic fever, glomerulonephritis; *C. tetani* — drumstick spore; *M. tuberculosis* — airborne, AFB; *E. coli* — commonest UTI; *S.* Typhi — blood culture week 1, Widal later; *V. cholerae* — rice-water stools |
| Viruses | One nucleic acid; obligate intracellular; HIV, HBV, HCV by blood; HAV, HEV, polio, rotavirus faeco-oral; measles, varicella airborne |
| Fungi | Superficial — pityriasis versicolor; cutaneous — ringworm (dermatophytes); subcutaneous — mycetoma; deep — histoplasmosis; opportunistic — *Candida*, *Aspergillus*, *Mucor* |
| Parasites | *Plasmodium* (*Anopheles*) — blood smear; *E. histolytica* — dysentery, liver abscess; hookworm — skin, anaemia; *W. bancrofti* (*Culex*) — night blood; pinworm — tape test |
| Vectors | *Aedes* — dengue, chikungunya; *Culex* — filaria, JE; sandfly — kala-azar; rat flea — plague; mite — scrub typhus; housefly — typhoid, cholera, dysentery; rat urine — leptospirosis |
| Immunity | Innate (barriers, phagocytes, complement, NK, fever) vs acquired (active/passive; natural/artificial) |
| Immunoglobulins | IgG — most, crosses placenta; IgA — secretions, colostrum; IgM — first, pentamer; IgE — allergy; IgD — B-cell receptor |
| Hypersensitivity | I anaphylaxis (IgE); II cytotoxic (transfusion, Rh); III immune complex (serum sickness); IV delayed (Mantoux, contact dermatitis) |
| Serology | Widal — agglutination; VDRL — flocculation; ELISA — HIV, HBsAg; RDT — malaria, HIV |
| Vaccines | Live — BCG, OPV, MR, rotavirus; killed — IPV, rabies; toxoid — tetanus, diphtheria; recombinant — hepatitis B; conjugate — Hib, PCV |
| Cold chain | 2–8 °C; ILR, deep freezer, cold box, vaccine carrier; never freeze Hep B, Penta, DPT, Td, IPV (shake test); VVM square lighter than circle = use; reconstituted BCG, MR, JE within 4 hours |
| NIS (check current) | Birth: BCG, OPV-0, Hep B; 6/10/14 weeks: OPV, Penta, RVV (+ fIPV, PCV at 6 and 14); 9–12 months: MR-1, JE-1, PCV booster; 16–24 months: MR-2, JE-2, DPT-B1, OPV-B; 5–6 years: DPT-B2; 10 and 16 years: Td; pregnancy: Td-1, Td-2 or booster |

## Section B: Infection Control and Safety

| Topic | Key facts |
| --- | --- |
| HAI | Not present or incubating at admission; usually 48 hours or more after admission; CAUTI, SSI, VAP/VAE, CLABSI; rate per 1000 device-days |
| Bundles | CAUTI: indication, asepsis, closed system, bag below bladder, daily review. SSI: clippers not razor, antibiotic within 60 min before incision, chlorhexidine–alcohol, warmth, glucose. VAP: head up 30–45°, sedation break, oral care, subglottic suction. CLABSI: hand hygiene, maximal barrier, chlorhexidine, avoid femoral, scrub the hub, daily review |
| Surveillance | HICC (policy) and ICT (infection control officer + infection control nurse) |
| Precautions | Standard for all; contact (gloves, gown); droplet >5 µm (surgical mask, 1 m); airborne ≤5 µm (N95, negative pressure, 6–12 ACH) — TB, measles, chickenpox |
| PPE | On: gown → mask → goggles → gloves. Off: gloves → goggles → gown → mask; hand hygiene before and after |
| Hand hygiene | Rub 20–30 s; wash 40–60 s; soap and water for visible soil, *C. difficile*; 5 moments; WHO multimodal strategy; World Hand Hygiene Day 5 May |
| Spaulding | Critical — sterilize; semi-critical — HLD; non-critical — low-level |
| Sterilization | Autoclave 121 °C, 15 lb/in², 15–20 min (*Geobacillus stearothermophilus*); hot air oven 160 °C, 2 h (*Bacillus atrophaeus*); ETO for heat-sensitive; plasma; gamma rays (disposables); glutaraldehyde 2% for endoscopes |
| Spills | 1% hypochlorite, contact time, edge to centre, yellow bag |
| Specimens | Right specimen/site/time, before antibiotics, aseptic, labelled container, quick transport; 2 blood culture sets; MSU; catheter port not bag; CSF and blood cultures not refrigerated; triple packaging |
| BMW Rules 2016 (amended 2018, 2019) | Yellow — anatomical, soiled, discarded medicines, chemical, lab waste → incinerate. Red — recyclable contaminated plastics (tubing, catheters, syringes without needles, gloves) → autoclave, shred, recycle. White translucent — sharps. Blue — glass, metal implants. Segregate at source; ¾ full; bar code; ≤ 48 hours storage; CBWTF |
| Laundry | No shaking; bag at point of use; infected linen separate; closed trolleys; hot wash (≥71 °C for 25 min) |
| Stewardship | Right drug, dose, route, time, duration; culture first; 48–72 h review; de-escalate; NAP-AMR 2017; Red Line; AWaRe |
| MRSA/MDRO | Hand hygiene, contact precautions, screening, decolonisation, cleaning, stewardship |
| Incidents | Near miss / adverse event / sentinel event; report all; RCA (5 Whys, fishbone); CAPA |
| Safety indicators | Falls (Morse), restraints (order, least restrictive, release, document), transfusion (two-person check, first 15 min), IV complications, DVT, transport, surgical checklist (sign in, time out, sign out), medication reconciliation, SBAR, documentation |
| IPSG | Identify correctly (2 identifiers), effective communication (read back), high-alert medicines, safe surgery, reduce HAI, reduce falls; + clinical alarms |
| 5S | Sort, Set in order, Shine, Standardize, Sustain |
| Radiation / laser | ALARA — time, distance, shielding, TLD badge, AERB; laser Class 4, correct goggles, fire and plume precautions |
| Fire | Triangle: heat, fuel, oxygen; A solids, B liquids, C gases, D metals, electrical — CO2; RACE; PASS; no lifts |
| HAZMAT | Assess, protect, contain, clean, dispose, decontaminate, report; mercury — no vacuum or broom; MSDS/SDS |
| Codes | Red fire; Blue cardiac arrest; Pink child abduction; others vary |
| Disaster triage | Red immediate, yellow delayed, green minor, black dead |
| Employee safety | Hep B vaccine 0, 1, 6 months, anti-HBs ≥10 mIU/mL; NSI — wash, don't squeeze, report; HIV PEP ideally within 2 h, ≤ 72 h, 28 days (NACO); non-immune → HBIG + vaccine |

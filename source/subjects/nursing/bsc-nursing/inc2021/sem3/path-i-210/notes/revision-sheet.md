# Last-night revision sheet

Pathology I is examined with **Pathology II and Genetics next semester** (Section B of the Semester 4 paper), so this revision also sets you up for then. If you have one hour, learn the comparison tables below and the normal laboratory values.

**General pathology — key terms**

| Term | One-line meaning |
| --- | --- |
| Aetiology / pathogenesis | Cause / mechanism of a disease |
| Hypoxia / ischaemia / infarction | Low oxygen / low blood supply / tissue death from lost blood supply |
| Necrosis | Death of groups of cells in a living body (pathological) |
| Apoptosis | Programmed single-cell suicide, no inflammation |
| Atrophy / hypertrophy / hyperplasia | Smaller cells / bigger cells / more cells |
| Metaplasia / dysplasia | One cell type replaced by another / disordered premalignant growth |

**Must-know comparisons**

| Compare | Key difference |
| --- | --- |
| Reversible vs irreversible injury | Reversible = cell swelling, fatty change; irreversible = mitochondrial failure + membrane rupture |
| Coagulative vs liquefactive necrosis | Solid-organ infarcts vs brain infarct and abscess; caseous = TB; fat = pancreatitis |
| Dry vs wet gangrene | Dry: clear demarcation, slow, less toxaemia; wet: no line, fast, severe toxaemia; gas = Clostridium, crepitus |
| Apoptosis vs necrosis | Single cell, energy-needing, no inflammation vs groups of cells, passive, inflammation |
| Acute vs chronic inflammation | Neutrophils, exudate vs macrophages/lymphocytes/plasma cells, fibrosis |
| Transudate vs exudate | Low protein, clear, low SG (<1.012) vs high protein, cloudy, high SG (>1.020), cells |
| Benign vs malignant tumour | Slow, capsulated, no spread vs fast, invasive, metastasises, anaplastic |
| First vs second intention healing | Clean sutured wound, thin scar vs open wound, much granulation, large scar |
| Gastric vs duodenal ulcer | Pain soon after food, weight loss, can be malignant vs pain 2–3 h after/at night, relieved by food, rarely malignant |
| Rheumatoid vs osteoarthritis | Autoimmune, symmetrical small joints, morning stiffness vs wear-and-tear, weight-bearing joints, worse on use |
| Type 1 vs Type 2 diabetes | Young, insulin deficiency, ketosis-prone vs older, insulin resistance, obesity |

**Inflammation — sequences**

```text
Vascular: vasoconstriction → vasodilatation → increased permeability → stasis
Cellular: margination → rolling (selectins) → adhesion (integrins) → emigration → chemotaxis → phagocytosis → killing
```
Histamine = first mediator; C5a and LTB4 = chemotactic; C3b = opsonin; IL-1/TNF/IL-6 = fever and acute-phase response. Granuloma = epithelioid cells + Langhans giant cells + lymphocytes ± caseation (TB).

**Neoplasia**

- Carcinoma = malignant epithelial; sarcoma = malignant connective tissue; -oma usually benign (but melanoma, lymphoma are malignant).
- Carcinoma in situ = full-thickness dysplasia, basement membrane intact (not yet invading).
- Routes of spread: local invasion, lymphatic (carcinomas), blood (sarcomas), transcoelomic (body cavities).
- Grade = how abnormal the cells look; stage (TNM) = how far it has spread — stage matters more for prognosis.

**Circulation and fluids**

- Virchow's triad (thrombosis): endothelial injury, altered blood flow (stasis/turbulence), hypercoagulability.
- Emboli: thromboembolism (commonest), fat, air, amniotic fluid; pulmonary embolism from DVT.
- Shock types: hypovolaemic, cardiogenic, distributive (septic, anaphylactic, neurogenic), obstructive. Stages: non-progressive → progressive → irreversible.

**Systemic pathology — one-liners**

| Disease | Remember |
| --- | --- |
| Lobar pneumonia | 4 stages: congestion → red hepatisation → grey hepatisation → resolution |
| Pulmonary TB | Caseating granuloma; Ghon focus + node = Ghon complex; AFB on sputum |
| COPD | Chronic bronchitis (blue bloater, productive cough) + emphysema (pink puffer, air trapping) |
| Atherosclerosis | Lipid plaque in intima; risk: age, smoking, hypertension, diabetes, high LDL |
| Myocardial infarction | Coronary thrombosis; troponin and CK-MB rise; coagulative necrosis |
| Rheumatic heart disease | Follows group A streptococcal sore throat; mitral valve; Aschoff bodies |
| Cirrhosis | Diffuse fibrosis + regenerating nodules; causes alcohol, viral hepatitis |
| Viral hepatitis | A and E faeco-oral; B, C, D blood/body fluids; B and C → chronic, cirrhosis, cancer |
| Osteoporosis | Low bone mass, fragile bones; post-menopausal and senile; fractures of hip, spine, wrist |
| Goitre | Enlarged thyroid; simple (iodine lack) or toxic (Graves' — exophthalmos) |

**Laboratory normal values (adults)**

| Test | Normal (confirm with your lab) |
| --- | --- |
| Haemoglobin | Men ~13–17 g/dL, women ~12–15 g/dL |
| Total leucocyte count | 4,000–11,000 /µL |
| Platelet count | 1.5–4.5 lakh /µL (150,000–450,000) |
| PCV (haematocrit) | Men ~40–50%, women ~36–46% |
| ESR (Westergren) | Men <15 mm/h, women <20 mm/h |
| Bleeding time | 2–7 minutes |
| Prothrombin time | 11–16 seconds (reported with INR) |
| APTT | ~25–35 seconds |
| Fasting blood sugar | 70–100 mg/dL; diabetes ≥126 mg/dL |
| HbA1c | diabetes ≥6.5% |

PT tests the **extrinsic** pathway (warfarin); APTT tests the **intrinsic** pathway (heparin); BT tests platelet and vessel function.

**Blood bank**

- ABO: group A has anti-B, B has anti-A, AB none (universal recipient), O both (universal donor for red cells). Rh-negative mother + Rh-positive baby → haemolytic disease of the newborn.
- Cross-matching before every transfusion. Components: packed red cells, platelets, fresh frozen plasma, cryoprecipitate.
- **Acute haemolytic reaction** (ABO mismatch) is the most dangerous: fever, chills, back/loin pain, red urine, fall in blood pressure. **Stop the transfusion first, keep the line open with saline, inform the doctor and blood bank, return the unit.**

**Nursing links to quote**: turn bedridden patients to prevent pressure-sore necrosis; aseptic wound care; protein and vitamin C for healing; diabetic foot inspection to prevent gangrene; correct specimen tube, timing and labelling; identity and cross-match checks and close watch in the first 15 minutes of a transfusion.

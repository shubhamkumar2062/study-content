# Unit 1: Computer applications in patient care and nursing practice

This unit covers INC Unit I (10 hours theory, 15 hours lab). It is the largest unit of the course. It explains what a computer is, how nurses use computers in patient care, teaching, research and administration, and the basic software every nurse should be able to use: Windows, MS Office (Word, Excel, PowerPoint), the internet, literature search, statistical packages and the hospital management information system.

## 1.1 Basic terms

| Term | Meaning |
| --- | --- |
| Computer | An electronic machine that accepts data (input), processes it according to instructions (a program), stores it and gives results (output) |
| Data | Raw, unorganised facts, e.g. "38.6", "Bed 12" |
| Information | Data that has been organised and given meaning, e.g. "Patient in bed 12 has a temperature of 38.6 °C" |
| Hardware | The physical parts you can touch: monitor, keyboard, CPU, printer |
| Software | The programs (instructions) that tell the hardware what to do |
| Program | A set of step-by-step instructions written in a programming language |
| Network | Two or more computers connected to share data and devices |
| Informatics | The science of collecting, storing, processing and using data and information |

```text
   INPUT  ──►  PROCESSING (CPU)  ──►  OUTPUT
  keyboard        control unit         monitor
  mouse           arithmetic-logic     printer
  scanner         unit (ALU)           speaker
  barcode reader       │
                       ▼
                 STORAGE (memory)
          primary: RAM, ROM  |  secondary: hard disk, SSD, pen drive, cloud
```

## 1.2 Parts of a computer system

### Hardware

- **Input devices**: keyboard, mouse, touch screen, scanner, barcode scanner (used for patient wristbands and medicines), microphone, webcam, biometric reader.
- **Central processing unit (CPU)**: the "brain". It has a **control unit** (directs operations), an **arithmetic logic unit** (calculations and comparisons) and **registers** (very fast small memory).
- **Memory**:
  - **Primary memory**: **RAM** (random access memory) is temporary and is lost when power goes off; **ROM** (read-only memory) holds start-up instructions and is not lost.
  - **Secondary storage**: hard disk drive, solid-state drive, CD/DVD, pen drive, memory card, cloud storage.
- **Output devices**: monitor, printer, speaker, projector.
- **Units of storage**: bit (0 or 1) → byte (8 bits) → kilobyte (1024 bytes) → megabyte → gigabyte → terabyte.

### Software

| Type | What it does | Examples |
| --- | --- | --- |
| System software | Runs the computer itself | Operating systems: Windows, Linux, macOS, Android, iOS |
| Application software | Does a user's task | MS Word, Excel, PowerPoint, a web browser, a hospital information system |
| Utility software | Maintains the computer | Antivirus, backup, file compression |

### Types of computer by size

Supercomputer, mainframe (large hospitals and banks once used these), minicomputer/server, personal computer (desktop, laptop), handheld devices (tablet, smartphone). In wards today, nurses mostly use desktops at the nursing station, **computers on wheels** and tablets at the bedside.

## 1.3 Uses of computers in nursing

Computers support all four areas of nursing named in the syllabus.

| Area | Uses |
| --- | --- |
| **Nursing practice / patient care** | Electronic health records and nursing notes; vital-sign entry and charts; medication administration record with barcode checking; care plans; alerts (allergy, drug interaction, fall risk, early-warning scores); monitoring equipment (cardiac monitors, ventilators, infusion pumps); lab and radiology results; telehealth |
| **Nursing education** | Computer-assisted instruction, e-learning portals, online lectures, virtual classrooms, simulation (manikins controlled by software), e-books and e-journals, online tests, video demonstrations of procedures |
| **Nursing administration** | Staffing and duty rosters, patient classification and workload, bed management, inventory and stores, budgets, attendance, incident reporting, quality indicators, communication by e-mail and messages |
| **Nursing research** | Literature search in databases, online questionnaires, data entry and storage, statistical analysis, reference management, writing and presenting the report |

### Advantages and limitations

| Advantages | Limitations |
| --- | --- |
| Legible, complete, quickly found records | Cost of hardware, software and training |
| Saves time on repeated work (calculations, reports) | Breakdowns, power and network failure |
| Fewer transcription and medication errors | Risk to privacy and confidentiality (hacking, misuse) |
| Alerts and reminders support safe care | Staff resistance and need for computer skills |
| Data can be shared across departments | "Screen time" can take attention away from the patient |
| Data available for audit, quality and research | Copy-paste and wrong-patient entries create new errors |

## 1.4 Windows (operating system)

An **operating system (OS)** manages the hardware and lets users run programs. Microsoft Windows uses a **graphical user interface (GUI)**: pictures (icons), windows, menus and a pointer.

Parts a student should know:

- **Desktop**: the main screen with icons and the **taskbar**.
- **Start menu**: opens programs, settings, power options.
- **File Explorer**: shows drives, **folders** and **files**; files have a name and an **extension** that shows the type (`.docx`, `.xlsx`, `.pptx`, `.pdf`, `.jpg`).
- Common actions: create a folder, rename, copy (Ctrl+C), cut (Ctrl+X), paste (Ctrl+V), undo (Ctrl+Z), save (Ctrl+S), delete (to Recycle Bin), search.
- **Control Panel / Settings**: date and time, users, display, printers.
- **Good practice in a hospital**: log in with your own user ID, never share passwords, lock the screen (Windows key + L) when leaving the computer, and log out at the end of the shift.

## 1.5 MS Office

### MS Word (word processing)

Used for nursing care plans, assignments, case studies, letters, reports, procedure manuals and theses.

- Typing and **editing**: cut, copy, paste, find and replace, spelling and grammar check.
- **Formatting**: font, size, bold, italic, underline, alignment, line spacing, bullets and numbering, headers and footers, page numbers, page margins.
- **Tables** (e.g. an intake–output chart), pictures, shapes, text boxes.
- **Mail merge**: one letter sent to many people with names filled in automatically.
- **Track changes and comments**: a teacher can correct a student's assignment.
- Save as `.docx` or export as `.pdf`.

### MS Excel (spreadsheet)

A spreadsheet is a grid of **rows** (numbers) and **columns** (letters); each box is a **cell** with an address such as **B4**. A file is a **workbook**; each page is a **worksheet**.

- Enter data such as vital signs, duty rosters, stock registers, research data.
- **Formulas** start with `=`: `=B2+B3`, `=SUM(B2:B31)`, `=AVERAGE(C2:C31)`, `=MAX()`, `=MIN()`, `=COUNT()`, `=IF()`.
- **Sort** and **filter** data (e.g. all patients above 65 years).
- **Charts**: line chart (temperature trend), bar chart (number of patients by ward), pie chart (percentage by diagnosis).
- **Conditional formatting**: highlight abnormal values in red.
- Example: a ward's monthly census with daily admissions, discharges and deaths; bed occupancy rate is worked out with a formula.

### MS PowerPoint (presentation)

Used for health education talks, seminars, case presentations and teaching.

- A file is a **presentation** made of **slides**; **slide layouts**, **themes** and the **slide master** keep the look consistent.
- Insert text, pictures, tables, charts, audio and video.
- **Transitions** (between slides) and **animations** (within a slide) should be used sparingly.
- **Views**: normal, slide sorter, reading view, slide show; **speaker notes** help the presenter.
- Good slides: one idea per slide, about six lines, large clear font, high contrast, no paragraphs read aloud.

## 1.6 The internet

- **Internet**: a worldwide network of networks. **World Wide Web (WWW)**: the collection of web pages reached through the internet using a **web browser** (Chrome, Edge, Firefox).
- **URL**: the address of a page; **https** (with a padlock) means the connection is encrypted.
- **Intranet**: a private network inside a hospital, used for policies, rosters and the hospital information system.
- **Services**: e-mail, search engines, websites, online learning, video-conferencing, cloud storage, social media.
- **Uses for nurses**: latest guidelines (MoHFW, INC, WHO), drug information, online courses and continuing nursing education, e-journals, telehealth, patient education material, professional networking.

**Judging whether a health website is reliable**

| Check | Ask |
| --- | --- |
| Authority | Who wrote it? A government body, university or professional body? |
| Accuracy | Is it supported by references and evidence? |
| Currency | When was it last updated? |
| Objectivity | Is it trying to sell something? |
| Privacy | Does it ask for personal data it does not need? |

## 1.7 Literature search

A **literature search** is a planned search of published material to find the best evidence on a topic. It is the first step of research and of evidence-based practice.

**Steps**

1. Frame a clear question, often in **PICO** form: Population, Intervention, Comparison, Outcome. Example: In post-operative adults (P), does early ambulation (I) compared with bed rest (C) reduce chest infection (O)?
2. Choose **keywords** and their synonyms (e.g. "pressure ulcer", "bedsore", "pressure injury").
3. Choose databases:

| Database | Contents |
| --- | --- |
| PubMed (MEDLINE) | Biomedical and nursing journals; free to search; uses **MeSH** (Medical Subject Headings) |
| CINAHL | Nursing and allied health literature |
| Cochrane Library | Systematic reviews of treatments |
| Google Scholar | Broad scholarly search, free |
| Shodhganga | Indian theses and dissertations |

4. Combine terms with **Boolean operators**:
   - **AND** narrows (pressure ulcer AND elderly)
   - **OR** widens (bedsore OR pressure ulcer)
   - **NOT** excludes (pressure ulcer NOT diabetic)
   - Use quotation marks for an exact phrase and `*` for word endings (nurs* finds nurse, nurses, nursing).
5. Apply **limits**: years, language, age group, type of study.
6. Screen titles and abstracts, then read the full text of relevant articles.
7. Appraise the quality of each study and record the references (reference managers such as Zotero or Mendeley help).

## 1.8 Statistical packages

A **statistical package** is software that organises, analyses and presents data.

| Package | Notes |
| --- | --- |
| MS Excel | Basic descriptive statistics, charts; easy and widely available |
| SPSS | Menu-driven, widely used in nursing research for t-test, chi-square, correlation |
| Epi Info | Free package from the US CDC, used for surveys and outbreak data |
| R | Free, powerful, uses commands |
| STATA, SAS | Advanced packages used in large studies |

**Typical steps**: design a **codebook** (variables and codes, e.g. male = 1, female = 2) → enter data → **clean** it (check missing and impossible values) → **descriptive statistics** (frequency, percentage, mean, median, SD) → **inferential statistics** (chi-square, t-test, correlation) → tables and graphs → interpret with the help of a statistician.

## 1.9 Hospital management information system (HMIS)

A **hospital management information system** is software that connects all departments of a hospital so that data is entered once and shared. (The term **HMIS** is also used for the national **Health Management Information System** portal of NHM, which collects facility-level public health data; see Unit 6.)

**Modules usually found**

```text
                    ┌──────────────────────────┐
  Registration ─────┤                          ├───── Pharmacy
  (UHID, ABHA)      │   HOSPITAL MANAGEMENT    │
  OPD / IPD    ─────┤   INFORMATION SYSTEM     ├───── Laboratory (LIS)
  ADT          ─────┤  (shared database)       ├───── Radiology (RIS/PACS)
  Nursing      ─────┤                          ├───── Billing and insurance
  OT, ICU      ─────┤                          ├───── Stores, HR, payroll
                    └──────────────────────────┘
                        ▲ reports for managers
```

- **Patient registration** gives a **UHID** (unique hospital identification number); ADT = admission, discharge, transfer.
- **Clinical modules**: doctors' orders (computerised provider order entry), nursing notes, vital signs, medication administration, discharge summary.
- **Support modules**: lab, radiology, pharmacy, blood bank, diet, CSSD.
- **Administrative**: billing, insurance, inventory, HR, duty rosters, MIS reports.

**Benefits**: less paperwork, quicker results, fewer errors, accurate billing, real-time bed status, data for audits and accreditation.

**Problems**: cost, training, downtime, poor design that slows nurses, privacy risks.

**Example in India**: **e-Hospital**, developed by NIC for government hospitals, offers online registration, appointments and lab reports. Many large private hospitals use commercial systems.

**Nurse's role**: accurate and timely data entry, using one's own login, checking the right patient before entering data, reporting errors and downtime, giving feedback to the IT team, and following downtime procedures (paper forms) when the system fails.

## 1.10 Application in nursing

- Use a barcode scanner on the patient's wristband and the medicine before giving it.
- Enter vital signs at the bedside, not from memory at the end of the shift.
- Use Excel to make a duty roster or a ward census, and PowerPoint for a health talk.
- Search PubMed or CINAHL before writing a care plan for an unusual condition.
- Lock the screen and never share a password; you are responsible for every entry made under your login.

## Remember

- Data are raw facts; information is processed, meaningful data.
- Input → processing (CPU: control unit + ALU) → output; RAM is temporary, ROM is permanent.
- Operating system = system software (Windows); Word, Excel, PowerPoint = application software.
- Excel formulas begin with `=`; a cell address is column letter + row number (B4).
- Boolean AND narrows, OR widens, NOT excludes; PICO frames the question.
- PubMed uses MeSH; CINAHL is the nursing database; Cochrane gives systematic reviews.
- SPSS and Epi Info are statistical packages; Epi Info is free.
- HMIS links registration, clinical, support and administrative modules; UHID identifies the patient in one hospital.
- e-Hospital is the NIC hospital system used in government hospitals.

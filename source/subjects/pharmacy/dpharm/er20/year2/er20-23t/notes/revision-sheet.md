# Last-night revision sheet

If you have only a few hours, learn these with full diagrams and tables: **glycolysis**, **TCA cycle**, **urea cycle**, **β-oxidation of palmitic acid**, **ketone bodies and ketoacidosis**, **electron transport chain**, **regulation of blood glucose and diabetes**, **enzyme classification and inhibition**, **vitamins (coenzyme forms and deficiencies)**, **jaundice (three types)**, **liver and kidney function tests**, **lipid profile**, **lipoproteins**, **DNA structure**, **classification of proteins and amino acids**, **abnormal constituents of urine**, **ORS**.

> Normal values below are commonly quoted reference ranges, given as "about"; ranges vary by laboratory.

## Metabolism (Units 7–9)

| Pathway | Site | Key enzyme(s) | Energy / product |
| --- | --- | --- | --- |
| Glycolysis | Cytosol | Hexokinase, **PFK-1** (rate-limiting), pyruvate kinase | Net 2 ATP anaerobic; 7 (new) / 8 (old) aerobic; fluoride inhibits enolase |
| Pyruvate → acetyl CoA | Mitochondria | PDH complex (TPP, lipoate, CoA, FAD, NAD) | 1 NADH |
| TCA cycle | Mitochondrial matrix | Citrate synthase, isocitrate DH, α-KG DH | 3 NADH + FADH2 + GTP = 10 (12) ATP per acetyl CoA; amphibolic |
| Glucose total | – | – | 32 (new) / 38 (old) ATP |
| Glycogenesis / glycogenolysis | Cytosol, liver and muscle | Glycogen synthase (insulin) / phosphorylase (glucagon, adrenaline) | Liver has glucose-6-phosphatase; muscle does not |
| ETC | Inner mitochondrial membrane | Complexes I–IV, CoQ, cyt c; ATP synthase (V) | P/O NADH 2.5 (3), FADH2 1.5 (2); chemiosmotic theory (Mitchell) |
| Lipolysis | Adipose tissue | Hormone-sensitive lipase (↑ glucagon, adrenaline; ↓ insulin) | Glycerol + free fatty acids |
| β-Oxidation | Mitochondrial matrix | CPT-I (rate-limiting; inhibited by malonyl CoA) | Palmitate: 7 cycles, 8 acetyl CoA → 106 (129) ATP net |
| Ketogenesis | Liver mitochondria only | HMG-CoA synthase, lyase | Acetoacetate, β-hydroxybutyrate, acetone |
| Ketolysis | Extrahepatic tissues | Thiophorase (absent in liver) | Acetyl CoA → TCA |
| Urea cycle | Liver (mitochondria + cytosol) | **CPS-I** (N-acetylglutamate), OTC, ASS, ASL, arginase | 3 ATP (4 ~P); N from NH3 and aspartate |

| --- | --- |
| ETC inhibitors | Rotenone (I), antimycin A (III), cyanide, CO (IV), oligomycin (V); 2,4-DNP uncoupler |

| Glycogen storage | von Gierke (G-6-Pase), Pompe (acid maltase), McArdle (muscle phosphorylase) |

| Transamination | PLP; ALT: alanine ⇌ pyruvate; AST: aspartate ⇌ oxaloacetate |

## Minerals, water, electrolytes (Unit 10)

| Topic | Key facts |
| --- | --- |
| Ca | 99% bone; vitamin D ↑ absorption, phytate/oxalate ↓; rickets, osteomalacia, osteoporosis, tetany; plasma about 9–11 mg/dl |
| Fe / I / Zn | Haemoglobin – microcytic anaemia / thyroxine – goitre, cretinism / carbonic anhydrase – wound healing, hypogonadism |
| Cu / F / Se | Ceruloplasmin, Wilson's disease (excess) / caries (low), fluorosis (high) / glutathione peroxidase, Keshan disease |
| Body water | 60% of body weight: ICF 40%, ECF 20% (interstitial 15, plasma 5) |
| Water turnover | About 2.5 L/day; urine about 1.5 L; insensible loss about 0.8–0.9 L; metabolic water about 0.3 L |
| ECF vs ICF | Na+, Cl−, HCO3− vs K+, Mg2+, phosphate, proteins; Na+/K+-ATPase |
| Plasma electrolytes | Na about 135–145, K about 3.5–5.0, Cl about 96–106 mEq/L |
| ORS (low osmolarity) | NaCl 2.6, glucose 13.5, KCl 1.5, trisodium citrate 2.9 g/L; 245 mOsm/L; sodium–glucose co-transport; give zinc with ORS in children |

## Organ function tests (Unit 11)

| Test | About normal | Rises in |
| --- | --- | --- |
| Fasting plasma glucose | 70–100 mg/dl | Diabetes |
| Blood urea / BUN | 15–40 / 7–20 mg/dl | Kidney failure, dehydration, GI bleed |
| Serum creatinine | 0.6–1.2 mg/dl | Kidney failure (more reliable than urea) |
| Uric acid | 3.5–7 mg/dl (men) | Gout, kidney failure, leukaemia |
| Creatinine clearance | 90–140 ml/min | Falls in kidney disease; C = UV/P; inulin = gold standard for GFR |
| Total bilirubin / direct | 0.2–1.0 / up to 0.3 mg/dl | Jaundice |
| ALT / AST | 5–40 U/L | Hepatitis (ALT more liver-specific); AST also in MI |
| ALP | 40–130 U/L (adults) | Obstructive jaundice, bone disease |
| Albumin / A:G | 3.5–5 g/dl / 1.2–2 | Albumin ↓, A:G reversed in cirrhosis |
| Total cholesterol | Desirable < 200 mg/dl | Hypercholesterolaemia |
| LDL / HDL / TG | < 100 optimal / ≥ 60 protective (< 40 men, < 50 women low) / < 150 mg/dl | – |
| Friedewald | LDL = TC − HDL − TG/5 (TG < 400) | – |

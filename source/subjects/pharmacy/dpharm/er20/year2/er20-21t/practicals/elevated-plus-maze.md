# Anxiolytic activity using the elevated plus maze

**Aim:** To study the anxiolytic (anti-anxiety) activity of a drug such as diazepam in mice or rats using the elevated plus maze, by simulation.

## Principle

The elevated plus maze is a plus (+) shaped platform raised above the floor, with **two open arms** (no walls) and **two closed arms** (with high walls) meeting at a central square. Rodents naturally fear open and high spaces, so normally they spend more time in the **closed arms**. **Anxiolytic drugs** (benzodiazepines) reduce this fear, so animals make **more entries into the open arms and spend more time there**. Anxiogenic drugs have the opposite effect.

```text
                 Open arm
                    │
   Closed arm ──── centre ──── Closed arm      (raised above the floor)
                    │
                 Open arm
```

## Requirements

Simulation software; in the simulated set-up: mice or rats, elevated plus maze, diazepam (standard), test drug, saline, stopwatch.

## Procedure

1. Divide the animals into control, standard and test groups and give saline, diazepam or test drug.
2. After the absorption time, place each animal in the central square facing an open arm.
3. For 5 minutes record:
   - number of entries into open arms and closed arms (all four paws in the arm);
   - time spent in open arms and closed arms.
4. Calculate the percentage of open-arm entries and time.

## Observations

| Group | Open-arm entries | Closed-arm entries | Time in open arms (s) | Time in closed arms (s) |
| --- | --- | --- | --- | --- |
| Control | | | | |
| Diazepam | | | | |
| Test drug | | | | |

```text
 % open-arm entries = Open-arm entries ÷ (Open + Closed entries) × 100
 % time in open arms = Time in open arms ÷ (Time in open + closed arms) × 100
```

## Result

Diazepam increased the number of entries into and the time spent in the open arms, showing anxiolytic activity.

## Precautions

1. Test each animal only once (repeated testing changes behaviour).
2. Keep the room quiet with constant dim light.
3. Clean the maze between animals.
4. Use the same starting position for all animals.

## Viva questions

1. **What is the basis of the elevated plus maze?** Natural fear of open, raised spaces in rodents.
2. **What change do anxiolytics produce?** More open-arm entries and more time in open arms.
3. **Standard drug?** Diazepam.
4. **Mechanism of benzodiazepines?** Increase frequency of GABA-A chloride channel opening.
5. **Name a non-benzodiazepine anxiolytic.** Buspirone.

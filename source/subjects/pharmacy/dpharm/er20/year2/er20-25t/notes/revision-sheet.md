# Last-night revision sheet

If you have only a few hours, learn these with full flow charts and tables: **P&T Committee and hospital formulary**, **tender procedure**, **EOQ, reorder level and ABC/VED** (with a calculation), **cold chain**, **unit-dose system vs floor stock**, **IV admixtures and incompatibilities**, **TPN**, **pharmaceutical care and DRPs**, **daily activities of the clinical pharmacist**, **LFT/RFT/electrolytes**, **antidotes**, **drug information sources**, **pharmacovigilance and PvPI**, **medication errors and LASA**, **drug interactions**.

## Supply chain and stores (Units 3–4)

| Formula / fact | Value |
| --- | --- |
| EOQ | √(2DS/H); ordering cost = carrying cost at EOQ |
| Safety stock | (max − normal daily use) × lead time |
| Reorder level | normal use × lead time + safety stock |
| Inventory turnover | consumption ÷ average inventory; days of stock = 365 ÷ turnover |
| ABC | A ≈ 10–20% items, ≈ 70% value; C ≈ 60–70% items, ≈ 10% value |
| VED | Vital, Essential, Desirable (criticality) |
| ABC–VED category I | AV, AE, AD, BV, CV |
| FSN | Fast, Slow, Non-moving |
| Tender | Open, limited, single; two-bid; EMD; L1; e-tender (CPPP, GeM) |
| Schedule H1 | Rx in red, boxed warning, register kept 3 years |
| NDPS storage | Double-locked cupboard, register, witness |
| FEFO | Earliest expiry issued first (preferred) |
| Cold chain | +2 to +8 °C; ILR (2–8 °C), deep freezer and WIF (about −15 to −25 °C), WIC (2–8 °C); VVM; shake test |
| Freeze-sensitive vaccines | HepB, pentavalent, DPT, Td, IPV, PCV |
| Expired / cytotoxic drugs | Yellow category, BMW Rules 2016; cytotoxics returned or incinerated above 1200 °C |

## Distribution, compounding, radiopharmacy, computers (Units 5–7)

| Item | Key point |
| --- | --- |
| Floor stock | Fast, but most errors and wastage; par level = use × interval + buffer |
| Unit dose | Ready-to-give single doses; ≤24 h on ward; fewest errors |
| Drug basket | One basket per patient for 24 h |
| ADC | Computer-controlled ward cabinet; BCMA scans wrist-band and dose |
| IV admixture | Aseptic in LAF; vertical LAF / Class II cabinet for cytotoxics |
| Incompatibility examples | Ca + PO4; Ca + bicarbonate; ceftriaxone + Ca; phenytoin in dextrose; amphotericin B in saline; insulin/nitroglycerin sorb to PVC |
| Drops per minute | volume × drop factor ÷ minutes |
| TPN energy | Dextrose 3.4, amino acids 4, lipid 9 kcal/g; NPC : N about 100–150 : 1 |
| Peripheral PN | Low osmolarity (below about 900 mOsm/L) |
| Radiopharmacy | Tc-99m about 6 h (Mo-99 generator); I-131 about 8 days; F-18 FDG about 110 min |
| Decay | A = A0 × (1/2)^(t/T½); decay-in-storage about 10 half-lives |
| ALARA | Time, distance, shielding; AERB; RSO |
| EHR vs EMR | Shared lifelong record vs one organisation's record; ABDM/ABHA |

## Laboratory values (Unit 10)

| Test | Typical adult value |
| --- | --- |
| Hb | Men 13–17, women 12–15 g/dL |
| WBC / platelets | 4,000–11,000/µL / 1.5–4.5 lakh/µL |
| MCV | 80–100 fL (low = iron deficiency; high = B12/folate) |
| INR on warfarin | Usually 2–3 |
| Bilirubin / ALT / ALP | 0.3–1.2 mg/dL / up to about 40 U/L / about 40–130 U/L |
| Creatinine / urea | 0.6–1.2 mg/dL / 15–40 mg/dL |
| Cockcroft–Gault | (140 − age) × wt / (72 × SCr), × 0.85 women |
| TSH | 0.4–4.0 mIU/L (high + low T4 = hypothyroid) |
| Troponin | Most specific MI marker; up 3–6 h, stays 7–14 days |
| Na / K / HCO3 | 135–145 / 3.5–5.0 / 22–28 mmol/L |
| Anion gap | Na − (Cl + HCO3), about 8–12 |
| Holliday–Segar | 100 / 50 / 20 mL/kg/day |
| Obstructive / restrictive | FEV1/FVC below 0.70 / FVC low, ratio normal or high |
| ABG | pH 7.35–7.45; PaCO2 35–45 mmHg |

## Poisoning and information (Unit 11)

| Poison | Antidote |
| --- | --- |
| Paracetamol | N-acetylcysteine (150 + 50 + 100 mg/kg over 21 h) |
| Organophosphate | Atropine + pralidoxime |
| Opioid / benzodiazepine | Naloxone / flumazenil |
| Heparin / warfarin | Protamine / vitamin K1 |
| Iron / lead / arsenic | Desferrioxamine / EDTA, DMSA / dimercaprol |
| Methanol / cyanide | Fomepizole or ethanol / hydroxocobalamin or nitrite + thiosulfate |
| Digoxin / isoniazid | Digoxin Fab / pyridoxine |
| Methaemoglobinaemia | Methylene blue |
| Snake bite / scorpion | Polyvalent ASV / prazosin |

Sources: **primary** = journals; **secondary** = PubMed, Embase, IPA; **tertiary** = Martindale, BNF, NFI, CIMS, IDR, Micromedex. Start tertiary → secondary → primary.

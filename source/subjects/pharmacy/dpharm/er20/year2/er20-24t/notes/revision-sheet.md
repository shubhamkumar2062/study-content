# Last-night revision sheet

If you have only a few hours, prepare full answers for: **rational use of medicines and essential medicines**, **hypertension**, **angina/MI**, **CHF**, **asthma vs COPD**, **diabetes**, **epilepsy**, **Parkinson's disease**, **peptic ulcer (H. pylori)**, **iron deficiency anaemia**, **tuberculosis**, **malaria**, **HIV**, **rheumatoid arthritis vs osteoarthritis**, **scabies**, **depression**, **glaucoma** and **antimicrobial resistance**.

## Chapter 1 basics

| Topic | Key point |
| --- | --- |
| Rational use (WHO 1985) | Right drug, right dose, right duration, lowest cost |
| WHO good prescribing | 6 steps; P-drug = personal drug chosen in advance |
| EBM | Best evidence + clinical expertise + patient values; Ask, Acquire, Appraise, Apply, Assess |
| Strongest evidence | Systematic review / meta-analysis of RCTs |
| Essential medicines | WHO first list 1977; India NLEM first 1996, latest 2022 (384 medicines), generic names, P/S/T levels |
| STG | Preferred drug, dose, duration for a disease; supports RUM |
| SOAP | Subjective, Objective, Assessment, Plan |

## Diseases at a glance

| Disease | Key fact | First-line / key drugs |
| --- | --- | --- |
| Hypertension | 140/90 or more; 90–95% essential; silent | ACE inhibitor/ARB, CCB, thiazide; methyldopa/labetalol/nifedipine in pregnancy |
| Angina | Ischaemia without necrosis | SL nitroglycerin (attack); beta-blocker, CCB (variant), aspirin, statin |
| MI | Necrosis; troponin rise; ACS | Aspirin, second antiplatelet, reperfusion (PCI/thrombolysis), heparin; ABCDE |
| Hyperlipidaemia | LDL main target | Statins; fibrates for high TG; ezetimibe |
| CHF | ↓ pump; RAAS + sympathetic over-activity | ACEI/ARB/ARNI + beta-blocker + spironolactone + SGLT2 inhibitor; furosemide for oedema; daily weight |
| Asthma | Reversible, variable, inflammatory | ICS (cornerstone), ICS–formoterol reliever, SABA; never SABA or LABA alone |
| COPD | Not fully reversible; smoking, biomass; FEV1/FVC below 0.70 | LAMA/LABA; stop smoking; vaccines; O2 88–92% in exacerbation |
| Diabetes | FPG 126, OGTT 200, HbA1c 6.5% | Type 1 insulin; type 2 metformin + lifestyle; SGLT2i/GLP-1 RA for heart/kidney |
| Hypothyroidism | High TSH | Levothyroxine empty stomach, apart from iron/calcium |
| Hyperthyroidism | Low TSH; Graves' | Carbimazole (PTU early pregnancy), propranolol; sore throat → agranulocytosis |
| Epilepsy | Recurrent unprovoked seizures | Valproate (generalised), carbamazepine (focal), ethosuximide (absence); IV lorazepam in status |
| Parkinson's | Dopamine loss, TRAP | Levodopa + carbidopa; avoid metoclopramide |
| Alzheimer's | Plaques, tangles, ↓ ACh | Donepezil, rivastigmine, galantamine; memantine |
| Stroke | CT first; BE FAST | Alteplase within 4.5 h (ischaemic); aspirin, statin; anticoagulant in AF |
| Migraine | One-sided throbbing, photophobia | NSAIDs, triptans; propranolol, flunarizine prophylaxis |
| GERD | Weak LES; heartburn | PPI before breakfast + lifestyle |
| Peptic ulcer | *H. pylori*, NSAIDs | PPI + clarithromycin + amoxicillin 14 days; bismuth quadruple |
| Alcoholic liver disease | Fatty liver → hepatitis → cirrhosis | Abstinence, thiamine, benzodiazepines (withdrawal), spironolactone, lactulose, rifaximin |
| IBD | UC: colon, continuous; Crohn's: skip, transmural | Mesalamine, steroids for flares, azathioprine, anti-TNF |
| Iron deficiency anaemia | Microcytic; low ferritin, high TIBC | Ferrous sulfate; 3 months after Hb normal; black stools |
| Megaloblastic anaemia | Macrocytic; B12 → nerve damage | IM hydroxocobalamin; folic acid 5 mg; never folate alone in B12 lack |
| Tuberculosis | Cough 2 weeks+; CBNAAT | 2HRZE/4HRE; pyridoxine; rifampicin orange urine |
| Pneumonia | *S. pneumoniae*; CURB-65 | Amoxicillin / macrolide; ceftriaxone + azithromycin in hospital |
| UTI | *E. coli*; 10⁵ CFU/mL | Nitrofurantoin, fosfomycin; avoid fluoroquinolones in pregnancy |
| Hepatitis | A/E faeco-oral; B/C blood | B – tenofovir/entecavir, vaccine; C – sofosbuvir-based DAAs 12 weeks |
| Gonorrhoea | Gram-negative diplococci | Ceftriaxone + azithromycin; treat partner |
| Syphilis | Painless chancre; VDRL/TPHA | Benzathine penicillin G 2.4 MU IM |
| Malaria | *Anopheles*; vivax relapses | Vivax: chloroquine + primaquine 14 days; falciparum: ACT + single primaquine; severe: IV artesunate |
| HIV | CD4 below 200 = AIDS | Treat all; TLD; PEP within 72 h for 28 days; cotrimoxazole prophylaxis |
| COVID-19 | SARS-CoV-2, ACE2 | Mild – home care; oxygen-requiring – dexamethasone + anticoagulant; vaccines |
| Rheumatoid arthritis | Symmetrical small joints; stiffness more than 1 h | Methotrexate weekly + folic acid; biologics |
| Osteoarthritis | Weight-bearing joints; pain on use | Weight loss, exercise, topical NSAID, paracetamol |
| Psoriasis | Silvery plaques, Auspitz sign | Topical steroid + calcipotriol; methotrexate; no systemic steroids |
| Scabies | Night itch, burrows | Permethrin 5% neck down 8–12 h, repeat day 7; treat contacts |
| Eczema | Barrier defect, itch | Emollients daily + topical steroid; tacrolimus |
| Depression | 2 weeks, SIG E CAPS | SSRIs; 2–4 weeks to act; continue 6–12 months; taper |
| Anxiety | Excess worry, panic | CBT + SSRI/SNRI; benzodiazepines 2–4 weeks only |
| Psychosis | Hallucinations, delusions; dopamine excess | Antipsychotics; EPS (typical), weight gain (atypical), clozapine needs blood counts |
| Conjunctivitis | Bacterial purulent; viral watery | Topical antibiotic for bacterial only; hygiene |
| Glaucoma | Optic nerve damage; IOP 10–21 normal | Latanoprost, timolol, brimonidine, dorzolamide; acute: acetazolamide, mannitol, pilocarpine |
| AMR | Enzymes, target change, efflux, low permeability | Stewardship; Schedule H1 2013, Red Line 2016, NAP-AMR 2017 |
| PCOS | Rotterdam 2 of 3 | Weight loss; COC; metformin; letrozole/clomiphene |
| Dysmenorrhoea | Prostaglandins | NSAIDs early + heat; COC |
| PMS | Luteal phase symptoms | Lifestyle, calcium; SSRIs; drospirenone COC |

## Danger signs to quote in counselling answers

- Chest pain not relieved by nitrate in 5 minutes → emergency.
- Weight gain of about 2 kg in 2–3 days in heart failure → call the doctor.
- Sore throat and fever on carbimazole or clozapine → blood count.
- Rash on carbamazepine or lamotrigine → stop and report.
- Yellow eyes on TB drugs → liver check; blurred colour vision on ethambutol.
- Dark urine on primaquine → stop, check G6PD.
- Painful red eye with reduced vision or haloes → urgent eye referral.
- Thoughts of self-harm on antidepressants → seek help at once.

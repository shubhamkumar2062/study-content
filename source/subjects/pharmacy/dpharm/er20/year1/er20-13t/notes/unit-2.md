# Chapter 2: Classification of drugs

There are thousands of crude drugs. To study them in an orderly way, they are arranged into groups. No single system is perfect, so the syllabus asks for six systems: **alphabetical, taxonomical, morphological, pharmacological, chemical and chemo-taxonomical**. For each one, learn the basis, examples, merits and demerits.

```text
                     Classification of crude drugs
                                 |
  ---------------------------------------------------------------------
  |            |              |               |            |           |
Alphabetical Taxonomical  Morphological  Pharmacological  Chemical  Chemo-taxonomical
(A to Z)     (family,      (part used:     (action:        (main      (chemical
              genus)        leaf, bark…)    laxative…)      compound)  similarity in
                                                                       related plants)
```

## 2.1 Alphabetical classification

**Basis:** Drugs are arranged in the order of the letters A to Z by their Latin name or English (common) name.

**Where it is used:** Pharmacopoeias (Indian Pharmacopoeia, British Pharmacopoeia, United States Pharmacopeia), the National Formulary, dictionaries and encyclopaedias of drugs.

**Example (by English name):**

| Letter | Drugs |
| --- | --- |
| A | Acacia, Agar, Aloe, Ashwagandha, Asafoetida |
| B | Belladonna, Benzoin, Black pepper |
| C | Cardamom, Castor oil, Cinchona, Cinnamon, Clove, Coriander |
| D | Digitalis |
| E | Ephedra, Ergot |
| F | Fennel |
| G | Gelatin, Ginger, Gokhru, Guggul |

**Merits**

1. Simple; any drug can be found quickly.
2. Useful for reference books and stores.
3. Adding a new drug is easy.

**Demerits**

1. No relationship between neighbouring drugs; senna (laxative) may sit next to squill (expectorant).
2. Does not tell the source, part used, chemistry or action.
3. Latin and English names put the same drug in different places.

## 2.2 Taxonomical classification

**Basis:** Drugs are arranged according to the plant (or animal) they come from, following the natural system of plant classification: **kingdom → division → class → order → family → genus → species**. Common schemes are those of Bentham and Hooker and of Engler and Prantl.

**Example:**

| Family | Drugs |
| --- | --- |
| Solanaceae | Belladonna, Hyoscyamus, Datura, Ashwagandha |
| Umbelliferae (Apiaceae) | Coriander, Fennel, Ajwain, Asafoetida |
| Zingiberaceae | Ginger, Cardamom, Turmeric |
| Leguminosae (Fabaceae) | Senna, Acacia, Tragacanth, Liquorice, Guar gum |
| Rubiaceae | Cinchona, Ipecacuanha, Coffee, Pale catechu |
| Apocynaceae | Rauwolfia, Vinca |
| Liliaceae | Aloe, Squill, Colchicum |

```text
Example of the hierarchy for ginger

Kingdom  Plantae
Division Angiospermae
Class    Monocotyledonae
Order    Zingiberales (Scitamineae)
Family   Zingiberaceae
Genus    Zingiber
Species  officinale
```

**Merits**

1. Shows the natural relationship between plants.
2. Related plants often contain related chemicals (useful for finding new drugs).
3. Helps in correct botanical identification.

**Demerits**

1. Drugs with different actions sit together (Solanaceae has both potato and belladonna).
2. Same-family drugs may have different parts used and different uses.
3. Classification of plants keeps changing (Liliaceae has been split into several families), which can confuse students.

## 2.3 Morphological classification

**Basis:** Drugs are grouped by the **part of the plant or animal** that is used. Drugs are first divided into **organised** and **unorganised** drugs.

**A. Organised drugs** (have cells; are direct plant or animal parts)

| Part used | Examples |
| --- | --- |
| Leaves | Senna, Digitalis, Belladonna, Vasaka, Tea, Coca, Tulsi |
| Flowers / flower buds | Clove |
| Fruits | Coriander, Fennel, Black pepper, Gokhru, Myrobalan, Ajwain |
| Seeds | Ispaghula, Nutmeg, Colchicum, Coffee, Nux-vomica, Cardamom |
| Barks | Cinnamon, Cinchona, Arjuna |
| Woods | Sandalwood, Pterocarpus (heartwood) |
| Roots | Rauwolfia, Ashwagandha, Ipecacuanha |
| Rhizomes | Ginger, Turmeric, Podophyllum |
| Bulbs | Squill, Garlic |
| Herbs (whole plant, aerial parts) | Vinca, Punarnava, Ephedra (stems) |
| Fungi / sclerotia | Ergot |
| Galls | Nutgalls |

**B. Unorganised drugs** (no cells; obtained by incision, extraction, distillation or expression)

| Type | Examples |
| --- | --- |
| Dried latex | Opium, Papain |
| Dried juice | Aloe |
| Dried extracts | Black catechu, Pale catechu, Agar |
| Gums | Acacia, Tragacanth, Guar gum |
| Resins and balsams | Benzoin, Tolu balsam |
| Oleo-gum-resins | Asafoetida, Myrrh, Guggul |
| Fixed oils and fats | Castor oil, Almond oil, Olive oil, Cod liver oil |
| Waxes | Beeswax, Lanolin |
| Volatile oils | Clove oil, Lavender oil, Sandalwood oil |

**Merits**

1. Very useful for **identifying** drugs in the practical class and in the market.
2. Helps in detecting adulteration by comparing external features.
3. Easy for beginners.

**Demerits**

1. Ignores chemistry and action.
2. Drugs with different uses fall in one group (leaves include both laxative senna and cardiotonic digitalis).
3. One plant may give two parts with different uses (cinnamon bark and cinnamon leaf).

## 2.4 Pharmacological (therapeutic) classification

**Basis:** Drugs are grouped by their **action on the body** or the disease they treat. The drug list in Chapter 5 of this syllabus follows this system.

| Group | Examples |
| --- | --- |
| Laxatives / purgatives | Aloe, Castor oil, Ispaghula, Senna |
| Cardiotonics | Digitalis, Arjuna, Squill |
| Carminatives | Coriander, Fennel, Cardamom, Ginger, Clove, Cinnamon |
| Astringents | Myrobalan, Catechu, Galls |
| CNS stimulants | Tea, Coffee |
| Anticholinergics | Belladonna, Hyoscyamus |
| Antihypertensive | Rauwolfia |
| Expectorant / antitussive | Vasaka, Tolu balsam, Squill |
| Antimalarials | Cinchona, Artemisia |
| Antitumour | Vinca, Podophyllum |
| Antidiabetics | Gymnema, Pterocarpus |
| Diuretics | Gokhru, Punarnava |

**Merits**

1. Most useful for **pharmacists and doctors**, because drugs used for the same purpose are studied together.
2. Helps in choosing a substitute drug.

**Demerits**

1. One drug may have several actions (cinchona: antimalarial and bitter tonic; quinidine from it is antiarrhythmic), so it fits more than one group.
2. Different chemical types and different parts are mixed.

## 2.5 Chemical classification

**Basis:** Drugs are grouped by their **main active chemical constituent**.

| Chemical group | Examples |
| --- | --- |
| Alkaloids | Cinchona, Opium, Belladonna, Rauwolfia, Ergot, Vinca |
| Glycosides — anthraquinone | Senna, Aloe |
| Glycosides — cardiac | Digitalis, Squill |
| Glycosides — saponin | Liquorice, Arjuna |
| Tannins | Myrobalan, Catechu, Galls |
| Volatile oils | Clove, Cinnamon, Fennel, Cardamom |
| Resins | Benzoin, Tolu balsam, Asafoetida |
| Carbohydrates (gums, mucilage) | Acacia, Tragacanth, Agar, Ispaghula |
| Lipids (fixed oils, fats, waxes) | Castor oil, Beeswax, Lanolin |
| Proteins and enzymes | Papain, Pancreatin, Gelatin |
| Vitamins | Cod liver oil, Shark liver oil, Yeast |

**Merits**

1. Explains the action of the drug and helps in its **chemical evaluation** (assay and tests).
2. Very useful for phytochemical research.

**Demerits**

1. Many drugs contain more than one important group (cinchona has alkaloids and tannins).
2. Structures of some active compounds are not known, so they cannot be placed.

## 2.6 Chemo-taxonomical classification

**Basis:** It combines **taxonomy with chemistry**. Plants that are related in taxonomy often produce similar chemicals, and the presence of a particular chemical is used as an extra character to classify plants. It is also called **chemosystematics**.

| Chemical marker | Plant group where it is typical |
| --- | --- |
| Tropane alkaloids (hyoscyamine, hyoscine) | Solanaceae (belladonna, hyoscyamus, datura) |
| Cardiac glycosides | Scrophulariaceae (digitalis), Apocynaceae |
| Indole alkaloids | Apocynaceae (rauwolfia, vinca), Loganiaceae (nux-vomica) |
| Volatile oils in secretory canals (vittae) | Umbelliferae (coriander, fennel) |
| Volatile oils in glandular hairs | Labiatae (tulsi, lavender, rosemary) |
| Betalain pigments in place of anthocyanins | Caryophyllales |
| Isoquinoline alkaloids | Papaveraceae (opium), Berberidaceae |

**Merits**

1. Helps settle doubtful positions of plants in classification.
2. Guides the **search for new drugs**: if one species contains a useful compound, related species are screened first.
3. Helps find substitutes (for example, *Digitalis lanata* for *D. purpurea*).

**Demerits**

1. Needs chemical analysis of many plants; not practical for beginners.
2. A chemical may occur in unrelated plants (caffeine in tea, coffee and cocoa from three different families), so the rule has exceptions.

## 2.7 Comparison of the systems

| System | Basis | Best for |
| --- | --- | --- |
| Alphabetical | Name order | Reference books, pharmacopoeias |
| Taxonomical | Family, genus, species | Botanists, natural relationships |
| Morphological | Part used | Identification, practicals |
| Pharmacological | Action / use | Pharmacists, doctors |
| Chemical | Main constituent | Analysis, phytochemistry |
| Chemo-taxonomical | Chemistry + taxonomy | Research, new drug search |

## Remember

- Six systems: alphabetical, taxonomical, morphological, pharmacological, chemical, chemo-taxonomical.
- **Pharmacopoeias use alphabetical** order.
- Morphological divides drugs into **organised** (cellular) and **unorganised** (non-cellular) drugs.
- Pharmacological classification is the most useful one for pharmacists; Chapter 5 follows it.
- Chemical classification helps in assays and tests; its demerit is drugs with more than one group of constituents.
- Chemo-taxonomy = related plants make related chemicals (tropane alkaloids in Solanaceae).
- In an exam answer, give each system with its basis, two or three examples, merits and demerits.

# Systematic qualitative analysis of organic compounds

**Aim:** To identify the given organic compound (about 4 substances during the course) by systematic qualitative analysis.

> Typical unknowns: benzoic acid, salicylic acid, phenol, β-naphthol, aniline, acetanilide, benzamide, urea, glucose, acetone, chloroform. Use small amounts.

## Principle

An organic compound is identified step by step: physical characters → ignition test → solubility class → detection of elements (N, S, halogens) by Lassaigne's test → tests for functional groups → melting/boiling point → derivative (if required). Each step narrows the possibilities.

## Requirements

Test tubes, ignition tube, sodium metal (handled with forceps, stored under kerosene), FeSO4, FeCl3, dilute H2SO4, sodium nitroprusside, lead acetate, AgNO3, HNO3, NaOH, NaHCO3, HCl, H2SO4, 2,4-DNP reagent, Schiff's reagent, Tollens' and Fehling's reagents, Molisch reagent, β-naphthol, NaNO2.

## Procedure

**1. Preliminary tests**

| Test | Observation | Inference |
| --- | --- | --- |
| State, colour, odour | e.g. white crystalline, phenolic odour | Possible phenol |
| Ignition on spatula | Sooty smoky flame | Aromatic compound |
| | Non-sooty flame | Aliphatic compound |
| Charring with smell of burnt sugar | | Carbohydrate |

**2. Solubility**

| Solvent | Soluble | Inference |
| --- | --- | --- |
| Water | Yes | Low-molecular polar compound (urea, glucose, acids, small amines) |
| 5% NaOH, insoluble in water | Yes | Acid or phenol |
| 5% NaHCO3 (with effervescence) | Yes | Carboxylic acid (stronger acid) |
| 5% HCl | Yes | Amine (base) |
| Conc. H2SO4 | Yes | Neutral compound with O or N (ketone, ester, amide) |

**3. Lassaigne's test (sodium fusion):** fuse a little compound with a small piece of sodium in an ignition tube, plunge into water, boil and filter (sodium fusion extract).

| Element | Test on extract | Observation |
| --- | --- | --- |
| Nitrogen | + FeSO4, boil, cool, add FeCl3 and dilute H2SO4 | Prussian blue colour/ppt |
| Sulphur | + sodium nitroprusside | Violet colour |
| Sulphur | + acetic acid + lead acetate | Black ppt |
| Halogens | Boil with dilute HNO3, add AgNO3 | White (Cl), pale yellow (Br), yellow (I) ppt |

**4. Functional group tests (examples)**

| Group | Test | Positive result |
| --- | --- | --- |
| Carboxylic acid | NaHCO3 | Brisk effervescence |
| Phenol | Neutral FeCl3 | Violet/green colour |
| Aldehyde | Schiff's reagent; Tollens' | Pink colour; silver mirror |
| Ketone | 2,4-DNP | Yellow-orange ppt; no Tollens' mirror |
| Primary aromatic amine | Diazotisation + β-naphthol | Orange-red dye |
| Amide | Warm with NaOH | Ammonia smell |
| Carbohydrate | Molisch's test | Violet ring |
| Ester | Hydroxamic acid test | Red-violet colour with FeCl3 |

**5. Physical constant:** determine melting point or boiling point and compare with tables.

## Precautions

1. Handle sodium with forceps; never touch water with it outside the procedure; destroy residues with ethanol.
2. Use small quantities; avoid tasting or direct smelling.
3. Run tests in order; record observations immediately.
4. Use a fume hood for fusion and strong acids.

## Viva questions

1. **What does a sooty flame indicate?** An aromatic (high carbon) compound.
2. **Why is sodium fusion done?** To convert covalently bound N, S and halogens into ionic sodium cyanide, sulphide and halides that can be tested.
3. **How do you distinguish a carboxylic acid from a phenol?** Acids dissolve in NaHCO3 with effervescence; most phenols do not.
4. **Test for aldehyde vs ketone?** Tollens' silver mirror (aldehyde only).
5. **Why must the Lassaigne's extract be boiled with HNO3 before the halogen test?** To decompose cyanide and sulphide which would also precipitate with AgNO3.

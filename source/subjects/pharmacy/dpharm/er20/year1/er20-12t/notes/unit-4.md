# Unit 4: Nomenclature of organic and heterocyclic compounds

Most drugs contain rings that include atoms other than carbon. To read a chemical name such as "7-chloro-1-methyl-5-phenyl-1,3-dihydro-2H-1,4-benzodiazepin-2-one" (diazepam), you need the basic rules of naming. The syllabus asks for an introduction, with special reference to heterocyclic compounds of up to three rings.

## 4.1 Why we need systematic names

A drug can have three kinds of name:

| Name | Example | Who uses it |
| --- | --- | --- |
| **Chemical (systematic / IUPAC) name** | N-(4-hydroxyphenyl)acetamide | Chemists; describes the exact structure |
| **Generic (non-proprietary) name** | Paracetamol (acetaminophen in the USA) | Pharmacopoeias, prescriptions, textbooks |
| **Brand (proprietary) name** | Crocin, Calpol, Dolo | Manufacturers; many brands for one generic |

The **IUPAC** (International Union of Pure and Applied Chemistry) system gives one clear name to each structure.

## 4.2 Basic IUPAC rules for open-chain and carbocyclic compounds (revision)

A systematic name has three parts: **prefix (substituents) + parent (root + saturation) + suffix (principal functional group)**.

**Word roots (number of carbons in the main chain)**

| C | Root | C | Root |
| --- | --- | --- | --- |
| 1 | meth- | 6 | hex- |
| 2 | eth- | 7 | hept- |
| 3 | prop- | 8 | oct- |
| 4 | but- | 9 | non- |
| 5 | pent- | 10 | dec- |

**Saturation:** -ane (all single bonds), -ene (C=C), -yne (C≡C).

**Functional group priority (highest first) and suffix / prefix**

| Group | Suffix | Prefix |
| --- | --- | --- |
| Carboxylic acid –COOH | -oic acid | carboxy- |
| Sulphonic acid –SO3H | -sulphonic acid | sulpho- |
| Ester –COOR | -oate | alkoxycarbonyl- |
| Acid halide –COX | -oyl halide | halocarbonyl- |
| Amide –CONH2 | -amide | carbamoyl- |
| Nitrile –CN | -nitrile | cyano- |
| Aldehyde –CHO | -al | formyl- / oxo- |
| Ketone >C=O | -one | oxo- |
| Alcohol –OH | -ol | hydroxy- |
| Amine –NH2 | -amine | amino- |
| (Only as prefixes) halogen, nitro, alkoxy | — | chloro-, nitro-, methoxy- |

**Steps**

1. Choose the longest chain (or ring) that contains the principal group.
2. Number it so the principal group gets the lowest number, then multiple bonds, then substituents.
3. Name substituents in **alphabetical order** with their position numbers (di-, tri- are ignored for alphabetising).
4. Use commas between numbers and hyphens between numbers and letters.

Examples: CH3CH(OH)CH3 = propan-2-ol; CH3COOH = ethanoic acid; aspirin = 2-acetoxybenzoic acid (2-(acetyloxy)benzoic acid).

**Benzene derivatives:** positions 1,2 = ortho (o-), 1,3 = meta (m-), 1,4 = para (p-). Paracetamol has –OH and –NHCOCH3 in para positions.

## 4.3 What is a heterocyclic compound?

A **heterocyclic compound** has a ring containing at least one atom other than carbon. These atoms are **heteroatoms**; the commonest in drugs are **nitrogen (N), oxygen (O) and sulphur (S)**.

```text
 Carbocyclic: benzene (all C)      Heterocyclic: pyridine (one N)
        ___                                 ___
       /   \                               /   \
      |     |                             |     |
       \___/                               \_N_/
```

Heterocycles are everywhere in medicine: nucleic acid bases (purines, pyrimidines), vitamins (thiamine, riboflavin, pyridoxine), alkaloids (morphine, quinine, atropine), and most synthetic drugs (benzodiazepines, phenothiazines, fluoroquinolones, azole antifungals, penicillins).

### 4.3.1 Classification

```text
                    HETEROCYCLES
        ┌───────────────┼────────────────┐
    By ring size    By number of rings   By saturation
    3,4,5,6,7…      mono-, bi-, tricyclic aromatic / partly
    membered        (fused)              saturated / saturated
```

## 4.4 Three ways of naming heterocycles

1. **Trivial (common) names** – historical names, still accepted by IUPAC for important rings: pyridine, furan, pyrrole, thiophene, indole, quinoline, purine.
2. **Hantzsch–Widman (systematic) system** – for monocyclic rings of 3 to 10 members.
3. **Replacement nomenclature** – the carbocycle name with "oxa", "aza", "thia" prefixes for the replaced carbon (e.g. 1-azacyclohexane is another way of describing piperidine).

### 4.4.1 Hantzsch–Widman system

**Name = prefix(es) for the heteroatom(s) + stem for ring size and saturation.**

**Prefixes for heteroatoms (in order of priority, highest first)**

| Heteroatom | Prefix |
| --- | --- |
| Oxygen | oxa- |
| Sulphur | thia- |
| Selenium | selena- |
| Nitrogen | aza- |
| Phosphorus | phospha- |
| Silicon | sila- |
| Boron | bora- |

(The final "a" is dropped before a vowel: "oxa" + "ole" = oxole.)

**Stems (ring size and saturation)**

| Ring size | Unsaturated, contains N | Saturated, contains N | Unsaturated, no N | Saturated, no N |
| --- | --- | --- | --- | --- |
| 3 | -irine | -iridine | -irene | -irane |
| 4 | -ete | -etidine | -ete | -etane |
| 5 | -ole | -olidine | -ole | -olane |
| 6 | -ine | -inane | -ine | -ane |
| 7 | -epine | -epane | -epine | -epane |
| 8 | -ocine | -ocane | -ocine | -ocane |

**Numbering rules**

1. The heteroatom gets position 1.
2. If there are different heteroatoms, number from the highest-priority one (O > S > N), then give the others the lowest possible numbers.
3. If there are two of the same heteroatom, give them the lowest numbers together.
4. "Indicated hydrogen" (e.g. 1H-, 2H-, 4H-) shows where the extra hydrogen sits when the ring could have it in more than one place (e.g. 1H-pyrrole, 2H-pyran).

**Examples**

| Hantzsch–Widman name | Common name | Ring |
| --- | --- | --- |
| Oxirane | Ethylene oxide | 3-membered, O, saturated |
| Aziridine | — | 3-membered, N, saturated |
| Azetidine | — | 4-membered, N, saturated (azetidin-2-one = β-lactam ring of penicillins) |
| Oxole | Furan | 5-membered, O |
| Thiole | Thiophene | 5-membered, S |
| Azole | Pyrrole | 5-membered, N |
| Azolidine | Pyrrolidine | 5-membered, N, saturated |
| 1,3-Diazole | Imidazole | 5-membered, two N |
| 1,2-Diazole | Pyrazole | 5-membered, two N side by side |
| 1,3-Oxazole | Oxazole | 5-membered, O and N |
| 1,3-Thiazole | Thiazole | 5-membered, S and N |
| 1,2,4-Triazole | Triazole | 5-membered, three N |
| Azine | Pyridine | 6-membered, N |
| 1,3-Diazine | Pyrimidine | 6-membered, two N (1,3) |
| 1,4-Diazine | Pyrazine | 6-membered, two N (1,4) |
| Azinane | Piperidine | 6-membered, N, saturated |
| 1,4-Oxazinane | Morpholine | 6-membered, O and N, saturated |
| Azepine | Azepine | 7-membered, N |

## 4.6 Fused (bicyclic and tricyclic) heterocycles

When two or more rings share a side (two adjacent atoms), they are **fused**. Many have trivial names that IUPAC keeps.

### 4.6.1 Fusion nomenclature (basic idea)

1. Pick the **base component** (the more important heterocycle, usually the one with nitrogen, or the larger ring with more heteroatoms).
2. The other ring is written as a prefix ending in "o": **benzo**, **naphtho**, **pyrido**, **thieno**, **furo**, **imidazo**.
3. The sides of the base ring are lettered a (1–2 bond), b (2–3 bond), c (3–4 bond) …; the letter in square brackets shows where fusion happens. Numbers before the letter show the atoms of the attached ring when needed.

Examples: **benzo[b]thiophene**, **thieno[2,3-b][1,5]benzodiazepine** (olanzapine nucleus), **pyrido[1,2-a]pyrimidine** (risperidone), **[1,2,4]triazolo[4,3-a][1,4]benzodiazepine** (alprazolam).

### 4.6.2 Two-ring (bicyclic) systems

```text
   Indole            Quinoline          Isoquinoline        Purine
    ___ ___           ___ ___            ___ ___            ___ ___
   /   X   \         /   X   \          /   X   \          N   X   N
   \___X_NH/         \___X_N_/          \___X___/          \_N_X_NH/
  (benzene +        (benzene +         (N at position 2)  (pyrimidine +
   pyrrole)          pyridine,                              imidazole)
                     N at 1)
```

| Ring system | Made of | Drug examples |
| --- | --- | --- |
| Indole | Benzene + pyrrole | Indomethacin, serotonin, tryptophan, ergot alkaloids |
| Benzimidazole | Benzene + imidazole | Albendazole, omeprazole |
| Benzothiazole / benzisoxazole | Benzene + thiazole / isoxazole | Risperidone (benzisoxazole) |
| Quinoline | Benzene + pyridine (N at 1) | Chloroquine, primaquine, quinine, mefloquine, fluoroquinolones (4-quinolone) |
| Isoquinoline | Benzene + pyridine (N at 2) | Papaverine, morphine-related alkaloids |
| Quinazoline | Benzene + pyrimidine | Prazosin, metolazone (quinazolinone) |
| Purine | Pyrimidine + imidazole | Caffeine, theophylline, mercaptopurine, acyclovir (guanine), adenine |
| Pteridine | Pyrimidine + pyrazine | Folic acid, methotrexate |
| Benzodiazepine | Benzene + 1,4-diazepine (7-membered, two N) | Diazepam, nitrazepam, clonazepam |
| Coumarin (2H-chromen-2-one) | Benzene + pyranone | Warfarin |
| Tropane (8-azabicyclo[3.2.1]octane) | Bridged bicyclic | Atropine, cocaine |
| Penam / cephem | β-lactam fused to thiazolidine / dihydrothiazine | Penicillins / cephalosporins |

### 4.6.3 Three-ring (tricyclic) systems

| Ring system | Structure | Drug examples |
| --- | --- | --- |
| Acridine | Two benzene rings fused to a central pyridine | Tacrine (tetrahydroacridine), acriflavine |
| Phenothiazine | Two benzene rings joined by S and N in a central six-membered ring | Chlorpromazine, promethazine |
| Phenoxazine | Same with O in place of S | Dactinomycin chromophore |
| Carbazole | Two benzene rings fused to a central pyrrole | Carvedilol |
| Dibenzazepine (iminostilbene) | Two benzene rings fused to a central seven-membered N ring | Imipramine, carbamazepine |
| Dibenzocycloheptene | Two benzene rings and a central seven-membered carbocycle | Amitriptyline (carbocyclic, not heterocyclic) |
| Thioxanthene | Phenothiazine with C in place of N | Flupentixol |
| Dibenzothiazepine / dibenzoxazepine | Central 7-membered ring with N and S/O | Quetiapine / loxapine |

## 4.7 Reading a drug name: worked examples

1. **Isoniazid = pyridine-4-carbohydrazide.** Pyridine ring; at position 4 a –CO–NH–NH2 (carbohydrazide) group.
2. **Phenytoin = 5,5-diphenylimidazolidine-2,4-dione.** Saturated five-membered ring with two N (imidazolidine); C=O at 2 and 4; two phenyl rings on C-5.
3. **Phenobarbital = 5-ethyl-5-phenylpyrimidine-2,4,6(1H,3H,5H)-trione.** Pyrimidine ring with three C=O; ethyl and phenyl on C-5.
4. **Fluconazole = 2-(2,4-difluorophenyl)-1,3-bis(1H-1,2,4-triazol-1-yl)propan-2-ol.** Propan-2-ol chain; at C-2 an –OH and a difluorophenyl ring; at C-1 and C-3 a triazole ring each ("bis" = two identical complex groups).
5. **Fluorouracil = 5-fluoropyrimidine-2,4(1H,3H)-dione.** Uracil (pyrimidine-2,4-dione) with F at 5.

## Remember

- Heterocycle = ring with at least one non-carbon atom (N, O, S).
- Hantzsch–Widman: prefix (oxa, thia, aza) + stem by size (-irine 3, -ete 4, -ole 5, -ine 6, -epine 7); "-olidine", "-inane" = saturated with N.
- Priority for numbering: O > S > N; heteroatom gets position 1.
- Fusion names: prefix in "o" (benzo, pyrido, thieno) + base ring + [letter] for the fused side.
- Know one drug for each ring: imidazole–ketoconazole, triazole–fluconazole, pyridine–isoniazid, pyrimidine–barbiturates/5-FU, piperazine–ciprofloxacin, quinoline–chloroquine, purine–caffeine/acyclovir, benzodiazepine–diazepam, phenothiazine–chlorpromazine, dibenzazepine–imipramine/carbamazepine.

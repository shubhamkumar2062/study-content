# Last-night revision sheet — MPH101T

## Unit 1: UV, IR, fluorescence, FES and AAS

- E = hν = hc/λ. UV 200–400 nm, visible 400–800 nm, mid-IR 4000–400 cm⁻¹.
- Transitions: σ→σ\* > n→σ\* > π→π\* (strong) > n→π\* (weak). Chromophore absorbs; auxochrome (–OH, –NH2) shifts to longer λ.
- Shifts: bathochromic (red), hypsochromic (blue), hyperchromic (up), hypochromic (down). Polar solvent: π→π\* red, n→π\* blue.
- A = εbc = 2 − log %T; ε = A(1%, 1 cm) × M/10. Paracetamol A(1%, 1 cm) 715 at 257 nm → A 0.572 = 8.0 µg/mL.
- Beer's law deviations: real (> 0.01 M), chemical (equilibria), instrumental (polychromatic light, stray light).
- Sources: D2 lamp (UV), tungsten–halogen (visible), xenon (fluorimetry). Quartz below 350 nm. PMT, photodiode array.
- IR: needs dipole change; 3N − 6 (non-linear) / 3N − 5 (linear); ν̄ = (1/2πc)√(k/µ); C=O ~1720 cm⁻¹. Fingerprint 1500–600 cm⁻¹.
- IR frequency factors: bond strength and mass, conjugation (lower C=O), induction (raise), H-bonding (lower, broader), ring strain (raise), Fermi resonance, coupling.
- Sample handling: KBr pellet, Nujol mull, films, solution cells, ATR. Detectors: thermocouple, bolometer, Golay, DTGS, MCT.
- FTIR: Michelson interferometer + Fourier transform; Fellgett (multiplex), Jacquinot (throughput), Connes (wavenumber accuracy).
- Fluorescence: S1→S0, ns; phosphorescence T1→S0, slow. Stokes shift. Detector at 90°. Linear only when A < about 0.05.
- Fluorescence factors: rigidity, conjugation, substituents, heavy atoms, temperature, viscosity, pH, oxygen, concentration (inner filter). F0/F = 1 + K_SV[Q].
- FES = emission, temperature-sensitive, Na 589, K 766.5 nm. AAS = absorption by ground-state atoms; hollow cathode lamp; chopper; graphite furnace for trace.
- Interferences: spectral (background correction, D2/Zeeman), chemical (La/Sr releasing agent, EDTA protective), ionisation (Cs/K suppressor), matrix (standard addition).

## Unit 2: NMR

- I = 0 for even mass + even atomic number; 2I + 1 orientations; ¹H, ¹³C, ¹⁹F, ³¹P have I = 1/2.
- ν0 = γB0/2π: 9.4 T → 400 MHz (¹H), about 100 MHz (¹³C). Tiny Boltzmann excess → insensitive.
- T1 spin–lattice (energy to surroundings, sets repeat delay); T2 spin–spin (dephasing, line width).
- Instrument: superconducting magnet, shims, ²H lock, probe, RF transmitter/receiver, computer. Deuterated solvents (CDCl3 7.26). TMS = 0 ppm.
- δ = Δν(Hz)/spectrometer (MHz); field-independent. Downfield = deshielded.
- Shift factors: electronegativity, anisotropy (aromatic ring current, C=O, C≡C), H-bonding, exchange (D2O test), solvent, shift reagents.
- n + 1 rule, Pascal's triangle; J in Hz, independent of field. trans 12–18, cis 6–12, ortho 6–9, meta 1–3 Hz. Karplus: J vs dihedral angle.
- Double resonance: decoupling (collapses multiplets), NOE (through space, < 5 Å).
- FT-NMR: pulse → FID → Fourier transform; S/N ∝ √scans. 2D: COSY, HSQC, HMBC, NOESY.
- ¹³C: 1.1%, 0–220 ppm, broadband decoupled singlets, DEPT-135 (CH/CH3 up, CH2 down, C absent).

## Unit 3: Mass spectrometry

- Inlet → source → analyser (vacuum) → detector. m/z = B²r²e/2V. Base peak = 100%. M⁺• = molecular mass.
- EI 70 eV (hard, library); CI reagent gas → [M+H]⁺; FI/FD high field; FAB glycerol matrix + fast Ar/Xe atoms; MALDI matrix + 337 nm laser + TOF; ESI multiply charged, polar; APCI corona discharge, less polar; APPI Kr lamp + dopant, non-polar.
- Quadrupole: DC + RF mass filter; QqQ MRM for quantitation. TOF: t ∝ √(m/z), reflectron.
- Nitrogen rule: odd N → odd M. DBE = C − H/2 + N/2 + 1.
- α-cleavage, McLafferty (γ-H, m/z 44 aldehyde/74 methyl ester), tropylium 91, benzoyl 105 → 77, RDA.
- Metastable m* = m2²/m1 (105 → 77: 56.5).
- Isotopes: M+1 ≈ 1.1% × C; Cl 3:1; Br 1:1; Cl2 9:6:1; Br2 1:2:1; S raises M+2.

## Unit 4: Chromatography

- k = (tR − t0)/t0; α = k2/k1; N = 16(tR/W)²; H = L/N; Rs = 2ΔtR/(W1 + W2) ≥ 1.5; tailing ≤ 2.
- Rs = (√N/4)((α − 1)/α)(k/(1 + k)); H = A + B/u + Cu.
- Paper: partition, ninhydrin; TLC: adsorption on silica GF254, Rf; HPTLC: automated, densitometric.
- Column: wet packing, eluotropic series, fractions by TLC.
- Ion exchange: –SO3H (strong cation), –COOH (weak cation), quaternary ammonium (strong anion), DEAE (weak anion); DVB cross-linking; elute with salt/pH.
- GC: He/N2/H2; split/splitless/headspace; capillary columns; FID, TCD, ECD, NPD, MS; temperature programming; silylation.
- HPLC: degasser, pump, injector loop, C18 column, UV/PDA/fluorescence/RI/ELSD/MS; RP elutes polar first; pH 2 units from pKa; ICH Q2(R2) validation.
- Affinity: ligand + spacer arm + agarose; protein A (IgG), IMAC (His-tag); elute by pH, salt or competitor.

## Unit 5: Electrophoresis and XRD

- µ = v/E = q/6πηr. pI: no movement. Electro-osmosis towards cathode in silica capillaries. Joule heating limits voltage.
- Paper, gel (agarose for DNA; PAGE; SDS-PAGE by MW), capillary (CZE, MEKC, CGE, cIEF), zone (bands on support), moving boundary (Tiselius, free solution), IEF (pH gradient, focus at pI); 2D = IEF × SDS-PAGE.
- X-rays: Coolidge tube; continuous + Kα/Kβ; Cu Kα 1.5406 Å; Ni filter.
- nλ = 2d sin θ; 2θ = 20° → d = 4.44 Å (Cu Kα).
- Laue (white, stationary), rotating crystal (single crystal structure), powder (fingerprint, polymorphs, crystallinity, Scherrer size).
- 7 crystal systems, 14 Bravais lattices; polymorphs, solvates, co-crystals, amorphous halo.

## Unit 6: Immunoassays

- Hapten + carrier → antibody. Monoclonal = one epitope.
- RIA: labelled + unlabelled antigen compete for limited antibody; bound counts fall as analyte rises; ¹²⁵I (gamma), ³H (beta); separate bound/free; B/B0 vs log conc. IRMA: labelled antibody in excess.
- ELISA: coat → block → sample → conjugate → substrate → stop → read. HRP/TMB 450 nm; ALP/pNPP 405 nm.
- Direct, indirect (antibodies in serum), sandwich (two epitopes, signal ∝ conc), competitive (haptens, inverse); EMIT homogeneous.
- Bioluminescence: luciferin + ATP + O2 → light ~560 nm (firefly luciferase); luminometer; ATP viability, reporter genes, rapid microbiology, in vivo imaging.

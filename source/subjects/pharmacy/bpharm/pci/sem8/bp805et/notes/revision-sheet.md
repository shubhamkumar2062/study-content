# Last-night revision sheet — Pharmacovigilance

## Unit 1 — Basics and ADRs

| Topic | Key points |
| --- | --- |
| PV (WHO) | Science and activities for detection, assessment, understanding and prevention of adverse effects or any other drug-related problem |
| Why PV | Trials too few, too short, too simple, too median-aged, too narrow; rule of three (3n patients to see a 1-in-n event) |
| History | Sulfanilamide elixir 1937 → US 1938 Act; thalidomide withdrawn 1961; Yellow Card 1964; WHO programme 1968 (10 countries); UMC Uppsala 1978; ICH 1990; rofecoxib 2004 |
| WHO programme | VigiBase (database), VigiFlow (national centres), VigiAccess (public) |
| PvPI | Approved July 2010, AIIMS first NCC → IPC Ghaziabad April 2011; WHO-CC 2017; AMCs; helpline **1800-180-3024**; ADR PvPI app; consumer form |
| AE vs ADR | AE: no causal link needed; ADR: noxious, unintended, at normal doses |
| Types | A augmented, B bizarre, C chronic, D delayed, E end of use, F failure |
| Causality | WHO–UMC: certain, probable, possible, unlikely, conditional, unassessable. Naranjo (10 questions): ≥9 definite, 5–8 probable, 1–4 possible, ≤0 doubtful |
| Severity | Modified Hartwig–Siegel: levels 1–2 mild, 3–4 moderate, 5–7 severe |
| Seriousness | Death, life-threatening, hospitalisation/prolonged, disability, congenital anomaly, medically important |
| Preventability | Modified Schumock–Thornton (any "yes" = preventable) |

## Unit 2 — Classification and programmes

- **ATC**: 5 levels, 14 main groups, WHO Oslo centre; metformin A10BA02, paracetamol N02BE01.
- **DDD**: assumed average maintenance dose/day, main indication, adults; a unit, not a recommendation. DDD/1000 inhabitants/day; DDD/100 bed-days.
- **ICD-10** in use; **ICD-11** effective 1 January 2022.
- **INN** stems: -olol, -pril, -sartan, -dipine, -statin, -prazole, -oxacin, -vir, -mab, -tinib.
- **MedDRA** (ICH; MSSO; March and September releases): SOC (27) → HLGT → HLT → PT → LLT; code at LLT, count at PT; one primary SOC. **SMQs** narrow vs broad.
- **WHO-ART** older, replaced by MedDRA; **WHODrug** (UMC) codes medicines with ATC; **xEVMPD** (EMA) EU products.
- Industry case flow: receipt → validity → triage → entry → coding → medical review → narrative → QC → submission → follow-up.
- MAH stays responsible when a **CRO** does PV work.

## Unit 3 — Vaccines, methods, communication

- **AEFI** types: vaccine product, quality defect, immunisation error, immunisation anxiety, coincidental. WHO causality: consistent / indeterminate / inconsistent / unclassifiable. Brighton case definitions.
- **Vaccine failure**: primary (no immunity) vs secondary (waning).
- Passive (spontaneous: cheap, rare new ADRs; under-reporting, no denominator) · stimulated · active (sentinel sites, PEM, registries).
- Cross-sectional → prevalence; case-control → **OR = ad/bc** (rare outcomes); cohort → **RR = [a/(a+b)]/[c/(c+d)]** (incidence).
- Signal: possible causal link, unknown or incompletely documented. **PRR = [a/(a+b)]/[c/(c+d)]**, ROR = ad/bc; screen PRR ≥2, χ² ≥4, ≥3 cases. UMC uses IC; FDA uses EBGM.
- Crisis: plan, one spokesperson, fast honest messages; DHPC letters; Erice Declaration 1997.

## Unit 4 — Safety data and ICH

- Pre-clinical: acute, repeat-dose, safety pharmacology (S7A/S7B), genotoxicity, carcinogenicity, reproductive toxicity.
- ICH 1990 (EU, Japan, USA; regulators + industry), Council since 2015; Q, S, E, M.
- **E2A** expedited · **E2B** ICSR · **E2C** PSUR → PBRER (R2, 2012) · **E2D** post-approval · **E2E** PV planning · **E2F** DSUR · **E6** GCP (R3 adopted 2025).
- Expedited = serious + unexpected: fatal/life-threatening **7 days** (+8 days follow-up); others **15 days**.
- Valid case: patient, reporter, drug, reaction.
- PSUR keys: International Birth Date, data lock point, reference safety information.
- E2E: safety specification (identified risks, potential risks, missing information) + PV plan (routine + additional) → RMP.

## Unit 5 — Genes, special groups, CIOMS, CDSCO

| Gene | Drug → ADR |
| --- | --- |
| CYP2D6 ultrarapid | Codeine → morphine toxicity |
| CYP2C9 (+VKORC1) | Warfarin → bleeding |
| CYP2C19 poor | Clopidogrel → treatment failure |
| NAT2 slow | Isoniazid → neuropathy; hydralazine → lupus |
| TPMT | Azathioprine → marrow suppression |
| DPYD | 5-FU → severe toxicity |
| Pseudocholinesterase | Succinylcholine → apnoea |
| G6PD | Primaquine, dapsone → haemolysis |
| HLA-B\*15:02 / \*57:01 / \*58:01 | Carbamazepine SJS / abacavir hypersensitivity / allopurinol SJS |

- Children: grey baby (chloramphenicol), kernicterus (sulphonamides), teeth (tetracyclines), Reye's (aspirin).
- Pregnancy: weeks 3–8 organogenesis; FDA letters → PLLR 2015; registries.
- Lactation: weak bases trapped in milk; RID under about 10%.
- Elderly: polypharmacy, renal decline, falls; Beers, STOPP/START.
- **CIOMS** 1949 (WHO + UNESCO); I = form, II = PSUR, III = core safety info, IV = benefit–risk, VI = trial safety, VII = DSUR, VIII = signals, IX = risk minimisation.
- **CDSCO** (DCGI); D&C Act 1940, Rules 1945; **Schedule Y** (2005) → **NDCT Rules 2019**; PSUR 6-monthly × 2 years then annual × 2 years; trial SAE within 24 hours, analysed report within 14 days.

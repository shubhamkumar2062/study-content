# Last-night revision sheet

If you only have an hour, learn these five topics with full diagrams: **DNA replication (enzymes and fork)**, **transcription and mRNA processing**, **translation with the genetic code**, **lac operon (negative and positive control)**, and **GPCR second-messenger pathways**. Add **cell cycle checkpoints with apoptosis** if you have time. Together they cover most 10-mark questions.

**Unit 1 — Cells and chemical foundations**

- Cell theory: Schleiden and Schwann (1838–39); Virchow — every cell from a cell (1855).
- Fluid mosaic model (Singer–Nicolson 1972): phospholipid bilayer + integral/peripheral proteins + cholesterol + glycocalyx; about 7–10 nm.
- Transport: simple diffusion, facilitated (channels, GLUT), primary active (Na+/K+-ATPase, 3 out/2 in), secondary active (SGLT), endo/exocytosis.
- Prokaryote: no nucleus, circular DNA, 70S, peptidoglycan, binary fission. Eukaryote: nucleus, histones, 80S, organelles, mitosis.
- Bonds: covalent; weak = hydrogen, ionic, van der Waals, hydrophobic. Reactions: redox, group transfer, hydrolysis, condensation, isomerisation, C–C bond making/breaking.
- ΔG < 0 exergonic; ATP hydrolysis about −30.5 kJ/mol; enzymes lower activation energy only.

**Unit 2 — DNA and RNA**

| Item | Fact |
| --- | --- |
| B-DNA | Right-handed, antiparallel, about 10 bp/turn, 3.4 nm pitch, 2 nm wide |
| Base pairs | A=T (2 H-bonds), G≡C (3 H-bonds); Chargaff A = T, G = C |
| Replication | Semiconservative (Meselson–Stahl); helicase, SSB, gyrase, primase, pol III, pol I, ligase |
| Strands | Leading continuous; lagging as Okazaki fragments |
| Telomerase | RNA-containing reverse transcriptase; TTAGGG repeats |
| Cell RNA | rRNA about 80%, tRNA 15%, mRNA 5% |
| Ribosomes | 70S = 50S (23S, 5S) + 30S (16S); 80S = 60S (28S, 5.8S, 5S) + 40S (18S) |
| Bacterial promoter | −10 TATAAT (Pribnow), −35 TTGACA; σ factor |
| Eukaryotic RNA pols | I = rRNA; II = mRNA (α-amanitin sensitive); III = tRNA, 5S |
| mRNA processing | 5′ cap, splicing (GU…AG), poly-A tail |
| Code | 64 codons; AUG start; UAA, UAG, UGA stop; degenerate; wobble |
| Translation | Shine–Dalgarno; A, P, E sites; EF-Tu, peptidyl transferase (23S rRNA), EF-G; RF1/RF2 |

**Unit 3 — Proteins and gene control**

- 20 amino acids, L-form; glycine non-chiral; 9 essential in adults (His, Ile, Leu, Lys, Met, Phe, Thr, Trp, Val).
- Structure: primary (sequence) → secondary (α-helix 3.6/turn, β-sheet) → tertiary → quaternary (haemoglobin α2β2).
- Targeting: signal peptide + SRP → ER → Golgi; M6P → lysosome; NLS → nucleus. Degradation: ubiquitin → 26S proteasome.
- lac operon: lacZ, lacY, lacA; repressor (lacI) removed by allolactose; CAP–cAMP activates when glucose is low (positive control). trp operon: repressible, tryptophan = corepressor, attenuation.

**Unit 4 — Genetics and cell cycle**

- Mendel: 3:1 and 9:3:3:1. Autosomal recessive: sickle cell, CF, PKU. X-linked: haemophilia, G6PD deficiency.
- rDNA: restriction enzyme (EcoRI G^AATTC) → ligase → plasmid → transformation → selection.
- PCR: 94–95 °C / 50–65 °C / 72 °C, Taq. Southern DNA, Northern RNA, Western protein.
- Cycle: G1 → S → G2 → M; G0 resting. CDK4/6–D, CDK2–E, CDK1–B (MPF). Rb–E2F; p53 → p21.
- Checkpoints: G1/S, intra-S, G2/M, spindle assembly (Mad2, APC/C).
- Apoptosis: intrinsic (Bax/Bak → cytochrome c → Apaf-1 → caspase-9) and extrinsic (Fas/TNF → FADD → caspase-8) → caspase-3; DNA ladder; no inflammation.

**Unit 5 — Cell signalling**

| Pathway | Sequence |
| --- | --- |
| Gs | Receptor → Gs → adenylyl cyclase → cAMP → PKA → CREB |
| Gq | Receptor → Gq → PLC-β → IP3 (Ca2+) + DAG (PKC) |
| NO | NO → soluble guanylyl cyclase → cGMP → PKG; PDE5 breaks cGMP |
| RTK | Dimerise → autophosphorylate → Grb2–SOS → Ras → Raf → MEK → ERK |
| Insulin | IRS → PI3K → PIP3 → Akt → GLUT4 |
| Cytokine | Receptor → JAK → STAT → nucleus |

- Receptor families: ion channel (ms), GPCR (s), enzyme-linked (min–h), nuclear (h–days).
- Off switches: GTPase, PDE, phosphatases, GRK + β-arrestin.
- Misregulation: mutant Ras, BCR-ABL (imatinib), HER2, EGFR, BRAF V600E; cholera toxin (Gs on), pertussis toxin (Gi off).
- Kinases: ATP γ-phosphate → Ser/Thr/Tyr; ATP cleft is the drug site ("-tinib" drugs).

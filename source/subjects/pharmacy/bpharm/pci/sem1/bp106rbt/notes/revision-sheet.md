# Last-night revision sheet

If you have only an hour, prepare these as full answers with a diagram: **five-kingdom classification**, **structure of heart and cardiac cycle**, **nephron and urine formation**, **neuron and nerve impulse**, **endocrine glands and hormones**, **photosynthesis (light and dark reactions)** and **mitosis vs meiosis**. The 10-mark question almost always comes from this list.

## Unit 1 — Living world and plant morphology

| Point | Fact |
| --- | --- |
| Defining characters of life | Metabolism, cellular organisation, response to surroundings |
| Taxonomic hierarchy | Kingdom → phylum/division → class → order → family → genus → species |
| Binomial nomenclature | Linnaeus; *Mangifera indica* — genus capital, epithet small, italics |
| Five kingdoms (Whittaker, 1969) | Monera (prokaryotes), Protista, Fungi (chitin wall), Plantae, Animalia |
| Virus | Nucleic acid + protein capsid; lives only inside host cells; TMV crystallised by Stanley |
| Root modifications | Carrot conical (Apiaceae), radish fusiform, turnip napiform (Brassicaceae), sweet potato tuberous |
| Stem modifications | Potato tuber (Solanaceae), ginger rhizome (Zingiberaceae), onion bulb, *Opuntia* phylloclade |
| Placentation | Marginal pea; axile China rose, tomato; parietal mustard; free central *Dianthus*; basal sunflower |
| Fruits | Mango drupe; tomato berry; apple pome (false); wheat caryopsis; jackfruit sorosis |
| Dicot vs monocot stem | Ring vs scattered bundles; open vs closed; collenchyma vs sclerenchyma hypodermis |
| Dicot vs monocot root | 2–4 xylem vs many; small vs large pith; both radial, exarch |

## Unit 2 — Blood, heart, digestion, breathing

| Point | Fact |
| --- | --- |
| Blood | Plasma 55% (water 90–92%), formed elements 45%; about 5 L |
| Counts | RBC about 5 million/mm³ (120 days); WBC 6,000–8,000; platelets 1.5–3.5 lakh |
| Clotting | Prothrombin → thrombin (Ca2+); fibrinogen → fibrin; vitamin K |
| Blood groups | O universal donor; AB universal recipient; Rh → erythroblastosis fetalis |
| Heart | Tricuspid right, bicuspid left; SA node pacemaker; 72 beats/min; cycle 0.8 s |
| Cardiac output | 70 ml × 72 ≈ 5 L/min |
| ECG | P atria depolarise; QRS ventricles depolarise; T ventricles repolarise |
| BP | 120/80 mmHg |
| Enzymes | Pepsin (HCl), trypsin (enterokinase), lipase (bile emulsifies), amylase |
| Fat absorption | Micelles → chylomicrons → lacteals |
| Breathing | Inspiration: diaphragm and external intercostals contract |
| Gas transport | O2 97% as oxyhaemoglobin; CO2 70% as bicarbonate (carbonic anhydrase) |
| Control | Rhythm centre medulla; pneumotaxic centre pons; CO2 and H+ main drivers |
| Volumes | TV 500, IRV 2,500–3,000, ERV 1,000–1,100, RV 1,100–1,200 ml; VC = TV + IRV + ERV |

## Unit 3 — Excretion, nerves, hormones, reproduction

| Point | Fact |
| --- | --- |
| Excretion modes | Ammonia (fish), urea (humans), uric acid (birds, reptiles, insects) |
| Nephron | Glomerulus + Bowman's capsule → PCT → loop of Henle → DCT → collecting duct |
| Urine formation | Filtration (GFR 125 ml/min, 180 L/day) → reabsorption (99%) → secretion |
| RAAS | Renin → angiotensin I → ACE → angiotensin II → vasoconstriction + aldosterone |
| Neuron | Dendrites in, axon out; myelin by Schwann cells; nodes of Ranvier |
| Impulse | Rest −70 mV; Na+ in = depolarisation; K+ out = repolarisation; pump 3 Na+ out, 2 K+ in |
| Brain parts | Cerebrum thinking; cerebellum balance; hypothalamus temperature, hunger, thirst; medulla breathing, heart |
| Spinal cord | Grey matter inside (H), white outside; 31 pairs spinal nerves; reflex arc |
| Hormones | Insulin lowers glucose, glucagon raises; ADH water; oxytocin labour; thyroxine metabolism; adrenaline emergency |
| Disorders | Gigantism/acromegaly (GH), goitre (iodine), diabetes insipidus (ADH), diabetes mellitus (insulin) |
| Gametogenesis | Spermatogenesis: 1 → 4 sperm; oogenesis: 1 → 1 ovum + polar bodies |
| Menstrual cycle | 28 days; menstrual 1–5, follicular, ovulation day 14 (LH surge), luteal (progesterone) |

## Unit 4 — Mineral nutrition and photosynthesis

| Point | Fact |
| --- | --- |
| Essential elements | 17; macronutrients C, H, O, N, P, K, S, Ca, Mg; micronutrients Fe, Mn, Cu, Mo, Zn, B, Cl, Ni |
| Key roles | Mg in chlorophyll; Mo in nitrogenase; Zn for auxin; K for stomata |
| Symptoms | Mobile N, K, Mg → older leaves first; S, Ca → young leaves first |
| Nitrogen cycle | Fixation → ammonification → nitrification (*Nitrosomonas*, *Nitrobacter*) → denitrification (*Pseudomonas*) |
| Nodules | *Rhizobium* + legume; nitrogenase; leghaemoglobin keeps O2 low |
| Equation | 6CO2 + 12H2O → C6H12O6 + 6O2 + 6H2O; O2 from water |
| Light reaction | Grana; PS II (P680), PS I (P700); photolysis; ATP + NADPH + O2 |
| Calvin cycle | Stroma; RuBisCO; first product 3-PGA; 18 ATP + 12 NADPH per glucose |
| C4 plants | Maize, sugarcane; PEP carboxylase; OAA; Kranz anatomy |
| Limiting factors | Blackman (1905): light, CO2, temperature, water |

## Unit 5 — Respiration, growth, cell, tissues

| Point | Fact |
| --- | --- |
| Glycolysis | Cytoplasm; glucose → 2 pyruvic acid; net 2 ATP + 2 NADH |
| Fermentation | Yeast: ethanol + CO2; muscle and *Lactobacillus*: lactic acid |
| RQ | Carbohydrate 1; fat about 0.7; protein about 0.9 |
| Growth | Meristematic → elongation → maturation; sigmoid curve (lag, log, stationary) |
| PGRs | Auxin (apical dominance, rooting); GA (bolting); cytokinin (cell division); ABA (dormancy, stress); ethylene (ripening) |
| Cell theory | Schleiden, Schwann; Virchow — *omnis cellula e cellula* |
| Membrane | Fluid mosaic model, Singer and Nicolson (1972) |
| Organelles | Mitochondria powerhouse; lysosomes suicide bags; ribosomes protein synthesis (70S/80S) |
| Mitosis | 2n → 2n, 2 identical cells; prophase, metaphase, anaphase, telophase |
| Meiosis | 2n → n, 4 different cells; crossing over in pachytene |
| Plant tissues | Meristematic; simple (parenchyma, collenchyma, sclerenchyma); complex (xylem, phloem) |
| Animal tissues | Epithelial, connective, muscular, neural |

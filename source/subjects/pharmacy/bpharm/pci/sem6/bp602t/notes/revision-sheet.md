# Last-night revision sheet

If you only have an hour, learn these five topics with a classification table and a diagram each: **anti-asthmatic drugs**, **peptic ulcer drugs with *H. pylori* therapy**, **β-lactam antibiotics (penicillins and cephalosporins)**, **antitubercular drugs with regimens**, and **classification of anticancer drugs**. Together they cover most 10-mark questions. Add **antimalarials** and **immunosuppressants** if time allows.

**Unit 4**

- UTI: nitrofurantoin (urine only), methenamine (acid urine → formaldehyde). STD: syndromic approach.
- Anticancer: alkylating (cyclophosphamide → mesna), methotrexate (DHFR, folinic acid rescue), 5-FU (thymidylate synthase), vinca (no assembly), taxanes (no disassembly), etoposide (topo II), doxorubicin (heart), bleomycin (lung), cisplatin (kidney, ear), imatinib (BCR-ABL).
- Immunosuppressants: cyclosporine/tacrolimus (calcineurin), sirolimus (mTOR), mycophenolate (IMPDH), azathioprine (purines).
- mAbs: -ximab chimeric, -zumab humanised, -umab human. Biosimilar = highly similar, not identical.

**Unit 5**

- Acute (single, 14 days) → subacute (28 days) → subchronic (90 days) → chronic (≥6 months).
- Ames test = mutagenicity; thalidomide = teratogen; organogenesis = weeks 3–8.
- Poisoning headings: stabilise, diagnose, decontaminate, enhance elimination, antidote, support, prevent.
- Antidotes: naloxone, atropine + pralidoxime, chelating agents (dimercaprol, edetate, succimer, penicillamine).
- Circadian ≈ 24 h; SCN master clock; chronotherapy: evening statin, morning steroid, night cover in asthma.

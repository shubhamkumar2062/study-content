# Preliminary phytochemical screening of crude drugs

**Aim:** To prepare extracts of a given crude drug and detect the classes of phytoconstituents present by qualitative chemical tests.

> Follow your lab manual for exact quantities. Many reagents (Dragendorff's, Mayer's, concentrated acids) are toxic or corrosive: wear gloves and goggles, and heat solvents only on a water bath.

## Principle

Each class of plant constituent — alkaloids, glycosides, carbohydrates, proteins, saponins, tannins and phenolics, flavonoids, steroids and triterpenoids, fixed oils — gives a characteristic colour or precipitate with specific reagents. Extracting the powdered drug successively with solvents of increasing polarity (petroleum ether → chloroform → ethanol → water) separates constituents roughly by polarity, so each extract can be tested for the groups likely to be in it. A positive result shows only the presence of a group; it is a screening, not an assay.

```text
Dried, coarsely powdered drug
   │ petroleum ether (Soxhlet)  → fixed oils, sterols, waxes
   │ chloroform                 → aglycones, free alkaloid bases, terpenoids
   │ ethanol / methanol         → glycosides, flavonoids, tannins, alkaloid salts
   │ water (maceration)         → sugars, proteins, saponins, mucilage
   ▼
Each extract concentrated → chemical tests
```

## Requirements

**Chemicals:** petroleum ether, chloroform, ethanol, dilute HCl, dilute H2SO4, Dragendorff's, Mayer's, Wagner's and Hager's reagents, Molisch's reagent, Fehling's A and B, Benedict's reagent, biuret reagent, Millon's reagent, ninhydrin, 5% ferric chloride, lead acetate solution, gelatin solution, magnesium turnings, conc. HCl, conc. H2SO4, acetic anhydride, glacial acetic acid, sodium hydroxide, ammonia, benzene or chloroform for Borntrager test.

**Apparatus:** Soxhlet apparatus or conical flasks for maceration, water bath, test tubes, beakers, filter paper, evaporating dishes.

## Procedure

1. Dry and coarsely powder the drug; weigh about 20–50 g.
2. Extract successively with petroleum ether, chloroform and ethanol in a Soxhlet apparatus; macerate the marc with water. Concentrate each extract and note colour, consistency and yield.
3. Dissolve small portions of each extract in a suitable solvent and perform the tests below.

| Group | Test | Procedure | Positive result |
| --- | --- | --- | --- |
| Alkaloids | Dragendorff's | Extract in dilute HCl + reagent | Orange-red precipitate |
| | Mayer's | Acid solution + reagent | Cream precipitate |
| | Wagner's | Acid solution + iodine in KI | Reddish-brown precipitate |
| | Hager's | Acid solution + picric acid | Yellow precipitate |
| Carbohydrates | Molisch's | Solution + α-naphthol, then conc. H2SO4 along the side | Violet ring at the junction |
| Reducing sugars | Fehling's | Equal Fehling A + B, heat with extract | Brick-red precipitate |
| | Benedict's | Heat with Benedict's reagent | Red/orange precipitate |
| Proteins | Biuret | Extract + NaOH + dilute CuSO4 | Violet colour |
| | Millon's | Extract + reagent, warm | White precipitate turning red |
| Amino acids | Ninhydrin | Boil with ninhydrin | Purple colour |
| Cardiac glycosides | Keller–Killiani | Extract in glacial acetic acid + trace FeCl3, underlay conc. H2SO4 | Reddish-brown ring, blue-green upper layer |
| Anthraquinone glycosides | Borntrager's | Boil with dilute H2SO4, extract with benzene/chloroform, shake organic layer with ammonia | Pink-red ammoniacal layer |
| Saponins | Foam test | Shake extract with water | Persistent honeycomb froth |
| Tannins / phenolics | Ferric chloride | Extract + 5% FeCl3 | Blue-black or green-black colour |
| | Lead acetate | Extract + lead acetate | White precipitate |
| | Gelatin | Extract + 1% gelatin with NaCl | White precipitate |
| Flavonoids | Shinoda | Ethanolic extract + magnesium turnings + conc. HCl | Pink to red colour |
| | Alkaline reagent | Extract + NaOH | Yellow colour, lost on adding acid |
| Steroids / triterpenoids | Liebermann–Burchard | Chloroform extract + acetic anhydride + conc. H2SO4 | Blue-green (steroids) or red-violet (triterpenoids) |
| | Salkowski | Chloroform extract + conc. H2SO4 | Red lower layer (sterols) |
| Fixed oils | Spot test | Press extract on filter paper | Permanent oily stain |

## Precautions

1. Use dry, finely powdered drug and pure solvents.
2. Run a blank (reagent alone) for each colour test.
3. For alkaloid tests, remove proteins (they also precipitate with alkaloidal reagents) or confirm with more than one reagent.
4. Add concentrated H2SO4 slowly down the side of the tube.
5. Heat inflammable solvents only on a water bath, away from flames.

## Viva questions

1. **Why is successive extraction used?** — It separates constituents by polarity so each extract is enriched in certain groups.
2. **Which reagent gives an orange precipitate with alkaloids?** — Dragendorff's reagent (potassium bismuth iodide).
3. **Name a test for 2-deoxy sugars of cardiac glycosides.** — Keller–Killiani test.
4. **What does the Shinoda test detect?** — Flavonoids (pink-red with magnesium and HCl).
5. **Why do saponins froth?** — They are surface-active glycosides that lower surface tension.
6. **Why can a protein-rich extract give a false alkaloid test?** — Proteins are also precipitated by alkaloidal reagents.
7. **What does Borntrager's test detect?** — Free anthraquinones (O-glycosides after hydrolysis).

# Last-night revision sheet

If you only have an hour, learn these five topics fully: **the shikimic acid and mevalonate pathways with their products**, **the monographs of opium, belladonna, digitalis, senna and clove**, **isolation of caffeine, atropine and quinine with their identification tests**, **industrial production of diosgenin, digoxin and paclitaxel**, and **TLC, HPLC and the four spectroscopic methods**. Together they cover most 10-mark questions.

**Unit 1 in one table**

| Topic | Key points |
| --- | --- |
| Three building blocks | Acetyl-CoA (C2), shikimic acid, amino acids; isoprene C5 from mevalonate or MEP |
| Shikimic acid pathway | PEP + erythrose-4-P → DAHP → dehydroquinic → dehydroshikimic (→ gallic acid) → shikimic → EPSP → chorismic acid → phenylalanine, tyrosine, tryptophan |
| Phenylpropanoids | PAL: phenylalanine → cinnamic acid → coumarins, lignans, eugenol, anethole, lignin |
| Flavonoids | Ring B + C3 from shikimate, ring A from 3 malonyl-CoA (chalcone synthase) |
| Acetate–malonate | Polyketides: fatty acids, anthraquinones (senna, aloes), tetracyclines |
| Acetate–mevalonate | 3 acetyl-CoA → HMG-CoA → mevalonic acid → IPP/DMAPP → GPP C10 → FPP C15 → GGPP C20 → squalene C30 → phytoene C40 |
| Terpene classes | Mono C10 menthol, sesqui C15 artemisinin, di C20 taxol, tri C30 glycyrrhetinic acid, tetra C40 carotenoids |
| Alkaloid precursors | Ornithine → tropanes; lysine → piperidines; tyrosine → morphine, berberine; tryptophan + secologanin → strictosidine → reserpine, vinca, quinine; histidine → pilocarpine; purines → caffeine |
| Tracers | 14C and 3H most used; feeding by roots, wick, cut shoot, injection, 14CO2, cell culture |
| Tracer methods | Precursor–product with degradation, competitive feeding, sequential (pulse) analysis, double labelling, mutants, grafting |
| Formula | % incorporation = activity in product × 100 ÷ activity fed |

**Unit 3 — isolation in one line each**

| Compound | Key step |
| --- | --- |
| Menthol | Steam-distil mint oil, chill, crystals of menthol separate; dementholised oil remains |
| Citral | Bisulphite addition compound, wash, decompose with alkali |
| Artemisinin | Hexane extraction, dewaxing, silica column, crystallise |
| Glycyrrhetinic acid | Ammonia extract → acidify → glycyrrhizic acid → acid hydrolysis → aglycone |
| Rutin | Boiling water or hot methanol, crystallises on cooling |
| Atropine | Alkali + solvent, acid–base purification, racemise hyoscyamine, crystallise as sulphate |

| Podophyllotoxin | Alcohol percolate poured into acidified water → resin → chromatography |

**Unit 5**

| Topic | Key points |
| --- | --- |
| Extraction steps | Size reduction → wetting → dissolution → diffusion |
| Classical | Maceration, percolation, digestion, infusion, decoction, Soxhlet, counter-current, distillation, expression |
| Modern | Supercritical CO2 (31 °C, 74 bar; no residue), microwave, ultrasound, pressurised solvent, enzyme-assisted |
| Rf | Distance of solute ÷ distance of solvent front; always < 1 |
| Paper chromatography | Partition; water on cellulose; n-butanol : acetic acid : water |
| TLC | Adsorption on silica gel G; UV 254/365, iodine, anisaldehyde–H2SO4, Dragendorff; HPTLC adds densitometry |
| GC | Volatile, stable samples; carrier gas; FID; volatile oils |
| HPLC | Reverse phase C18, polar compounds elute first; PDA, fluorescence, ELSD (no chromophore), MS |
| UV | A = ε c l; conjugation; flavonoid shift reagents; caffeine 273 nm, curcumin about 425 nm |
| IR | Functional groups; fingerprint region 1500–600 cm−1 for identity |
| NMR | Chemical shift, integration, multiplicity, coupling constant; 13C and 2D for structure |
| MS | Molecular ion gives molecular weight; GC–MS and LC–MS for trace work |
| Electrophoresis | Charge and size in an electric field; agarose for DNA fingerprinting of plants, PAGE for proteins, capillary for small molecules |
| Standardisation | Identity → purity limits → fingerprint → marker assay; active versus analytical marker |

**Five facts that are easy marks**

1. Glyphosate blocks EPSP synthase of the shikimic acid pathway, which animals do not have.
2. Digoxin comes from *Digitalis lanata*, digitoxin from *D. purpurea*.
3. Atropine is racemic and optically inactive; hyoscyamine is laevorotatory.
4. Aloin is a C-glycoside, so it needs the modified Borntrager test.
5. Artemisinin has no useful UV absorption, so HPLC with an evaporative light-scattering detector is used.

# Last-night revision sheet

Focus your final hour on five answers: **β-lactam antibiotics (penicillin mechanism + generations of cephalosporins)**, **aminoglycoside pharmacology (mechanism + ototoxicity/nephrotoxicity)**, **antimalarial drugs (chloroquine + ACTs with life-cycle stages)**, **classification of anticancer drugs with one example per class and its unique toxicity**, and **fluoroquinolone mechanism + adverse effects**. These cover the most-tested long and short questions.

## Mechanisms — one line each

| Drug / Class | Mechanism |
| --- | --- |
| Penicillins, cephalosporins, carbapenems | Inhibit PBPs (transpeptidase) → block peptidoglycan cross-linking → cell wall lysis (bactericidal) |
| Vancomycin | Binds D-Ala-D-Ala terminus of peptidoglycan precursor → blocks transglycosylation (bactericidal; Gram-positive only) |
| Aminoglycosides | Bind 30S ribosome → misreading of mRNA → faulty proteins → bactericidal; require O₂ for entry |
| Tetracyclines | Bind 30S ribosome → block aminoacyl-tRNA binding → bacteriostatic |
| Macrolides | Bind 50S ribosome → block translocation → bacteriostatic |
| Clindamycin | Bind 50S ribosome → bacteriostatic; anaerobes + Gram-positive; risk: *C. difficile* colitis |
| Fluoroquinolones | Inhibit DNA gyrase (Gram-negative) and topo IV (Gram-positive) → DNA strand breaks → bactericidal |
| Sulphonamides | Block DHPS → prevent PABA → no dihydrofolate synthesis |
| Trimethoprim | Block DHFR → no THF → no purine/pyrimidine synthesis (synergistic with sulphonamide) |
| Amphotericin B | Binds ergosterol → membrane pores → cell content leak → fungicidal |
| Azole antifungals | Inhibit CYP51 (14α-lanosterol demethylase) → ergosterol depletion → fungistatic |
| Aciclovir | Phosphorylated by viral TK → inhibits viral DNA polymerase (chain terminator) |
| Chloroquine | Prevents haem polymerisation in parasite food vacuole → toxic haem accumulates |
| Artesunate | Generates free radicals → damages parasite proteins |
| Metronidazole | Activated by anaerobic organisms → reactive radical → DNA strand breaks |
| Mebendazole/albendazole | Bind β-tubulin → impair microtubule polymerisation → impair glucose uptake in helminths |
| Alkylating agents | Alkylate guanine → DNA cross-links → replication blocked (CCNS) |
| Antimetabolites | Interfere with DNA/RNA synthesis (CCS, S-phase); MTX: folate antagonist; 5-FU: thymidylate synthase |
| Vinca alkaloids | Bind tubulin → prevent polymerisation → mitotic arrest (CCS, M-phase) |
| Taxanes | Stabilise polymerised microtubules → prevent depolymerisation → mitotic arrest (CCS, M-phase) |
| Anthracyclines | Intercalate DNA + inhibit Topo II + free radicals (CCNS) |
| Platinum compounds | Intrastrand/interstrand DNA cross-links (CCNS) |

## Adverse effects that always appear in exams

| Drug | Important ADR | Mnemonic / note |
| --- | --- | --- |
| Aminoglycosides | Ototoxicity (irreversible), nephrotoxicity | Monitor levels; avoid furosemide |
| Tetracyclines | Tooth discolouration, photosensitivity | Avoid < 8 yr, pregnancy |
| Fluoroquinolones | Tendinitis / tendon rupture (Achilles), cartilage damage | Avoid in children, athletes on steroids |
| Clindamycin | *C. difficile* pseudomembranous colitis | Treat with metronidazole or vancomycin |
| Sulphonamides | Stevens-Johnson syndrome, haemolysis in G6PD deficiency | Chelation with dairy/antacids irrelevant here |
| Amphotericin B | Nephrotoxicity, infusion reactions (fever, rigors), hypokalaemia | Liposomal form safer; premedicate |
| Metronidazole | Disulfiram-like reaction with alcohol, metallic taste | Avoid alcohol |
| Chloroquine | Retinopathy (long-term), haemolysis in G6PD | Test for G6PD before primaquine |
| Primaquine | Haemolysis in G6PD deficiency | Test G6PD; CI in pregnancy |
| Cyclophosphamide | Haemorrhagic cystitis | Prevent with mesna + hydration |
| Cisplatin | Nephrotoxicity (severe), ototoxicity, nausea/vomiting | Hydrate before and after; use anti-emetics |
| Doxorubicin | Cardiomyopathy (cumulative, lifetime dose limit) | Monitor LVEF; vesicant |
| Bleomycin | Pulmonary fibrosis | Monitor DLCO; not myelosuppressive |
| Vincristine | Peripheral neuropathy (dose-limiting) | Not myelosuppressive; constipation |
| Methotrexate | Mucositis, hepatotoxicity, nephrotoxicity | Folinic acid (leucovorin) rescue |
| L-Asparaginase | Hypersensitivity, pancreatitis, coagulopathy | Test dose first |

## Antimalarial drugs — by life-cycle phase

```text
Life cycle:
  Sporozoite (bite) → Liver (exoerythrocytic) → Merozoite
  → Red blood cell (erythrocytic: ring → trophozoite → schizont → merozoite + gametocyte)

Drugs by phase:
  Liver (tissue schizontocidal): primaquine, artemisinin (partial)
  Blood (erythrocytic / blood schizontocidal): chloroquine, quinine, artesunate, mefloquine
  Liver dormant stages (hypnozoites in P. vivax / P. ovale): primaquine only → "radical cure"
  Gametocytocidal: primaquine
```

**First-line treatment:**
- Falciparum: ACT (artemether-lumefantrine or artesunate-amodiaquine); artesunate IV for severe malaria
- Vivax/Ovale: chloroquine (radical cure with primaquine)

## Anticancer — class + unique toxicity (exam minimum)

| Class | Example | Unique toxicity |
| --- | --- | --- |
| Alkylating | Cyclophosphamide | Haemorrhagic cystitis (mesna); infertility |
| Platinum | Cisplatin | Nephrotoxicity + ototoxicity |
| Antimetabolite | Methotrexate | Mucositis; folinic acid rescue |
| Antimetabolite | 5-Fluorouracil | Mucositis; hand-foot syndrome |
| Vinca alkaloid | Vincristine | Peripheral neuropathy; not myelosuppressive |
| Taxane | Paclitaxel | Neuropathy + neutropenia; hypersensitivity (premedicate) |
| Anthracycline | Doxorubicin | Cardiomyopathy (dose-limited); vesicant |
| Topoisomerase I | Irinotecan | Delayed diarrhoea (atropine for early; loperamide for late) |
| Bleomycin | Bleomycin | Pulmonary fibrosis; NOT myelosuppressive |
| Hormonal | Tamoxifen | Endometrial cancer, DVT |

**CCS vs CCNS**:
- CCS (cell-cycle specific, kills only dividing cells): antimetabolites (S), vinca alkaloids (M), taxanes (M), bleomycin (G2/M)
- CCNS (kills resting and dividing): alkylating agents, platinum, anthracyclines

## Exam reminder

- Section A (20 marks, 10 × 2): expect one 2-mark answer per drug class — mechanism of one drug, one ADR, one use. Write precisely.
- Section B (20 marks, 2 × 10): classification questions are common — name 3–4 classes, one drug each, mechanism, uses. Tables earn marks efficiently.
- Section C (35 marks, 5 × 7): short notes typically ask you to write about one drug class (write mechanism → classification with examples → uses → ADR → contraindications in that order, 7 marks = 7 clear points).
- For every antibiotic short note: state bactericidal vs bacteriostatic and why (linking mechanism to activity tells the examiner you understand the pharmacology, not just memorised the fact).
- Never confuse mechanism with use: "blocks 30S ribosome" is mechanism; "used for atypical pneumonia" is clinical use; write both.

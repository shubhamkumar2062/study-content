# Last-night revision sheet

If you have only an hour, learn these six with full skeletons: **SAR of H1 antihistamines**, **thiazide SAR**, **steroid nucleus with numbering and the corticosteroid changes**, **cardiac glycoside SAR**, **sulphonylurea SAR** and **SAR of local anaesthetics**. Then read the synthesis table twice and the toxicity tags once.

## The six skeletons to draw from memory

```text
1. H1 antihistamine   Ar1 ╲
                           X — CH2CH2 — N(CH3)2
                      Ar2 ╱
                      X = O ethanolamine (sedative), N ethylenediamine,
                      C alkylamine (least sedative); amine must be tertiary

2. Thiazide           7-H2NO2S ─[ benzothiadiazine 1,1-dioxide ]─ 3-substituent
                      6-Cl or 6-CF3 essential; 3,4-dihydro = 10x potency

3. Steroid            rings A-B-C (6) + D (5); C18 on C13, C19 on C10
                      β up (bold), α down (dashed)
                      estrane 18C, androstane 19C, pregnane 21C

4. Cardiac glycoside  sugar(s) — steroid (14β-OH, cis ring fusions) — C17 lactone
                      lactone essential; sugars only change pharmacokinetics

5. Sulphonylurea      Ar(p-substituted) — SO2 — NH — CO — NH — R (3-6 carbons)

6. Local anaesthetic  Ar — [COO ester | NHCO amide] — CH2CH2 — N(C2H5)2
                      base enters the nerve, cation blocks Na+ channel inside
```

## Starred syntheses in one line each

| Drug | Route in one line |
| --- | --- |
| Diphenhydramine | Benzhydrol → benzhydryl chloride → 2-dimethylaminoethanol (Williamson) → HCl salt |
| Triprolidine | 4-Methylphenyl 2-pyridyl ketone → pyrrolidinyl side chain → dehydrate → separate the (E)-isomer |
| Promethazine | Phenothiazine + NaNH2 → 1-dimethylamino-2-chloropropane (branched 3-carbon chain) |
| Cimetidine | 4-Methyl-5-chloromethylimidazole + cysteamine → N-cyano-N',S-dimethylisothiourea |
| Mercaptopurine | Diaminopyrimidinol → formic acid (hypoxanthine) → P2S5 |
| Methotrexate | Tetraaminopyrimidine + dibromopropionaldehyde + p-methylaminobenzoylglutamic acid |
| Nitroglycerin, isosorbide dinitrate | Nitrate **esters**: controlled esterification of the polyol with nitric acid, then diluted and formulated (industrial; learn the reaction type, not a procedure) |
| Acetazolamide | Thiadiazole ring → acetylate the amine → chlorinate the SH to SO2Cl → ammonia |
| Chlorothiazide | m-Chloroaniline + chlorosulphonic acid → ammonia → formic acid ring closure (formaldehyde instead → hydrochlorothiazide) |
| Furosemide | 2,4-Dichlorobenzoic acid → chlorosulphonation → ammonia → furfurylamine |
| Methyldopate | Dimethoxyphenylacetone → Strecker → hydrolyse and demethylate → resolve (S) → esterify with EtOH/HCl |
| Disopyramide | Phenylacetonitrile + 2-chloropyridine → diisopropylaminoethyl chloride → partial hydrolysis to the amide → phosphate |
| Warfarin | 4-Hydroxycoumarin + benzylideneacetone, Michael addition |
| Tolbutamide | p-Toluenesulphonamide + n-butyl isocyanate (base) |
| Benzocaine | p-Nitrotoluene → oxidise → reduce to PABA → Fischer esterification with ethanol |
| Procaine | p-Nitrobenzoic acid → acid chloride → 2-diethylaminoethanol → reduce the nitro group → HCl salt |
| Dibucaine | 2-Hydroxycinchoninic acid → POCl3 → 2-diethylaminoethylamine (amide) → sodium butoxide |

## Mechanisms worth writing in full

```text
Histidine ──(decarboxylase)──► Histamine ; H1 = itch, wheal, bronchospasm
                                            H2 = gastric acid

R—O—NO2 → NO → guanylate cyclase → cGMP ↑ → veins dilate
          (tolerance: keep a nitrate-free interval)

Omeprazole (prodrug) → acid space of parietal cell → sulphenamide
          → S—S bond with H+/K+-ATPase → irreversible block

Nitrogen mustard → aziridinium ion → alkylates guanine N7 → cross-link

Vitamin K cycle ✗ warfarin blocks vitamin K epoxide reductase
          → factors II, VII, IX, X not carboxylated (effect after 2–3 days)

Digoxin ✗ Na+/K+-ATPase → Na+ ↑ inside → Ca2+ ↑ → stronger contraction

Sulphonylurea ✗ KATP channel → depolarise → Ca2+ in → insulin released

Local anaesthetic (base in, cation blocks) ✗ voltage-gated Na+ channel
```

## Confusions worth two minutes each

| Pair | How to tell them apart |
| --- | --- |
| Ethanolamine vs alkylamine antihistamine | O bridge = sedative and anticholinergic (diphenhydramine); C bridge = least sedative, most potent (chlorpheniramine) |
| Promethazine vs chlorpromazine | Branched three-carbon chain = antihistamine; straight three-carbon chain = antipsychotic |
| H2 blocker vs proton pump inhibitor | Competitive and reversible at the receptor vs irreversible at the pump |
| Chlorothiazide vs hydrochlorothiazide | 3,4-double bond vs saturated; saturation gives about ten times the potency |
| Loop vs thiazide diuretic | Loop loses calcium, works in renal failure; thiazide keeps calcium, fails at low GFR |
| Spironolactone vs amiloride | Aldosterone receptor antagonist (a steroid) vs direct sodium channel block |
| Nitro compound vs nitrate ester | R—NO2 is inactive here; R—O—NO2 releases nitric oxide |
| Digoxin vs digitoxin | One extra hydroxyl on digoxin: less lipophilic, less protein bound, shorter acting |
| Class IA vs IB antiarrhythmic | IA lengthens the action potential (quinidine), IB shortens it (lidocaine) |
| Cortisone vs hydrocortisone | 11-keto prodrug vs active 11β-hydroxy |
| Dexamethasone vs betamethasone | 16α-methyl vs 16β-methyl epimers |
| T4 vs T3 | Long acting, standard replacement vs fast and brief, for emergencies |
| Ester vs amide local anaesthetic | Plasma esterase, short, allergy through PABA vs liver, longer, rarely allergic |
| Benzocaine vs procaine | No basic amine, surface only vs basic amine, injectable as the hydrochloride |
| Sulphonylurea vs metformin | Releases insulin, causes hypoglycaemia and weight gain vs no insulin release, no hypoglycaemia alone |

## Numbers and facts worth memorising

| Fact | Value |
| --- | --- |
| Insulin | 51 amino acids, chain A 21 + chain B 30, two interchain disulphides |
| Steroid angular methyls | C18 on C13, C19 on C10 |
| Oestrogen carbons | 18 (aromatic ring A, no C19 methyl) |
| Prednisolone change | Δ1 double bond, about 4 times hydrocortisone |
| Dexamethasone / betamethasone | 9α-fluoro + 16-methyl, about 25–30 times, negligible salt retention |
| Alkylating agents attack | N7 of guanine |
| Warfarin onset | 2–3 days; monitored by INR; antidote vitamin K |
| Nitrate-free interval | 8–12 hours a day to avoid tolerance |
| Thiazide site | Distal convoluted tubule, Na+/Cl- carrier |
| Loop diuretic site | Thick ascending limb, Na+/K+/2Cl- carrier |
| Local anaesthetic blocked first | Small unmyelinated fibres: pain and temperature |
| Digitalis toxicity warning sign | Yellow-green vision; made worse by hypokalaemia |

## Named reactions used in this subject

Williamson ether synthesis (diphenhydramine) · Fischer esterification (benzocaine) · Michael addition (warfarin) · Strecker synthesis (methyldopate) · chlorosulphonation then ammonolysis (chlorothiazide, furosemide, acetazolamide, tolbutamide) · nucleophilic aromatic substitution (furosemide, dibucaine) · Grignard reaction (triprolidine) · partial nitrile hydrolysis to an amide (disopyramide) · aldol condensation (benzylideneacetone for warfarin).

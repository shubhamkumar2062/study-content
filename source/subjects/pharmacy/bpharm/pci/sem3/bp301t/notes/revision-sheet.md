**Common traps in MCQs**

- Halogens: **deactivating but ortho/para directing**.
- Benzene + Cl2: **FeCl3 → substitution** (chlorobenzene); **sunlight → addition** (BHC).
- BHC is a **cyclohexane**, not a benzene; only the **γ-isomer (lindane)** is active.
- Phenol does **not** react with NaHCO3; benzoic acid does.
- **Ortho effect**: ortho-substituted benzoic acids are stronger; ortho-substituted anilines are weaker.
- Naphthalene sulfonation: **80 °C → 1-**, **160 °C → 2-sulfonic acid**.
- Anthracene and phenanthrene react at **C9 and C10**.
- Baeyer predicted cyclopentane most stable; really **cyclohexane** is.
- Cyclopropane decolourises Br2 but **not** cold KMnO4.
- Acid value = **free** acid; saponification value = **free + combined** acid; ester value = SV − AV.

# Last-night revision sheet

If you have only one hour, learn these five with full diagrams: **moist heat and dry heat sterilisation with conditions**, **Gram staining with its mechanism**, **the bacterial growth curve**, **aseptic area and laminar flow**, and **the cup-plate microbiological assay**. Together they cover most of the 10-mark questions.

**Numbers to carry into the hall**

| Fact | Value |
| --- | --- |
| Autoclave | 121 °C, 15 psi, 15 min (also 115 °C/30 min, 126 °C/10 min, 134 °C/3 min) |
| Hot air oven | 160 °C for 2 h (170 °C/1 h, 180 °C/30 min) |
| Depyrogenation of glass | about 250 °C or above |
| Pasteurisation | 63 °C for 30 min (holder); 72 °C for 15 s (flash) |
| Tyndallisation | 100 °C, 20–30 min, on 3 successive days |
| Sterilising filter | 0.22 µm; sterility test membrane 0.45 µm |
| Gamma radiation dose | 25 kGy (2.5 Mrad), cobalt-60 |
| Germicidal UV | 254 nm (DNA absorbs near 260 nm) |
| HEPA filter | retains at least 99.97% of 0.3 µm particles |
| Laminar flow velocity | about 0.45 m/s (90 ft/min) |
| Sterility test incubation | 14 days; thioglycollate 30–35 °C, soyabean–casein digest 20–25 °C |
| Sterility assurance level | 10⁻⁶ |
| Bacterial cell size | 0.5–5 µm; viruses 20–300 nm |
| Light microscope resolution | about 0.2 µm; electron microscope about 0.2–0.5 nm |
| Agar in solid media | 1.5–2%; melts near 100 °C, sets near 40 °C |
| *E. coli* generation time | about 20 min in good conditions |
| Plate count range | 30–300 colonies per plate |
| Cell culture conditions | 37 °C, 5% CO2, pH 7.2–7.4, 5–10% serum |

**Mechanisms in one line each**

| Agent | How it kills |
| --- | --- |
| Moist heat | Coagulates and denatures proteins |
| Dry heat | Oxidises cell constituents |
| Ionising radiation | Free radicals break DNA |
| Ultraviolet | Thymine dimers block replication |
| Ethylene oxide | Alkylates proteins and nucleic acids |
| Phenols | Damage membrane, leakage; denature protein |
| Alcohol 70% | Denatures protein, dissolves lipids |
| Hypochlorite and iodine | Oxidation of cell proteins |
| Aldehydes | Alkylation |
| Quaternary ammonium compounds | Disrupt the cell membrane |
| Heavy metals | Bind sulphydryl groups of enzymes |

**Comparisons worth memorising**

| Pair | Key difference |
| --- | --- |
| Sterilisation / disinfection | Spores killed / spores may survive |
| Moist heat / dry heat | 121 °C, 15 min, coagulation / 160 °C, 2 h, oxidation |
| Gram-positive / Gram-negative | Thick peptidoglycan with teichoic acid / thin wall with outer membrane and endotoxin |
| Prokaryote / eukaryote | No nuclear membrane, 70S ribosomes / true nucleus, 80S ribosomes |
| Total count / viable count | Counts dead cells too / only living, as CFU |
| MIC / MBC | Stops visible growth / kills 99.9% |
| Cup-plate / turbidimetric assay | Zone diameter in 18–24 h / turbidity in 3–4 h |
| Primary / continuous cell line | From tissue, limited life / immortal, often aneuploid |

**Clean area grades:** A critical zone with unidirectional air (filling and open containers) → B background room → C and D supporting rooms. Positive pressure, air locks, HEPA filters, coved corners, people are the biggest source of contamination.

**Growth curve:** lag (adapting) → log (fastest, most sensitive, used in assays) → stationary (nutrients low, spores and antibiotics formed) → decline (death exceeds division).

**Virus replication:** adsorption → penetration → uncoating → biosynthesis (eclipse) → assembly → release.

**Spoilage checklist:** water activity, nutrients, pH, temperature, oxygen, packaging, formulation, contamination level, handling in use.

# Last-night revision sheet

If you only have an hour, learn these five topics with full mechanisms: **SN1 vs SN2**, **E1 vs E2 with Saytzeff's rule**, **Markownikoff and the peroxide effect**, **aldol + Cannizzaro**, and **acidity of acids / basicity of amines**. Together they cover most 10-mark questions. Then spend ten minutes naming structures.

**Mechanisms in one line each**

| Reaction | Key steps | Rate law / feature |
| --- | --- | --- |
| Free radical halogenation | Initiation (Cl2 → 2Cl·), propagation (Cl· + RH → HCl + R·; R· + Cl2 → RCl + Cl·), termination | 3° H > 2° > 1° |
| Electrophilic addition of HX | H⁺ adds → more stable carbocation → X⁻ adds | Markownikoff |
| Peroxide effect (HBr only) | RO· + HBr → Br·; Br· adds to give more stable radical; radical takes H from HBr | Anti-Markownikoff |
| Br2 addition | Cyclic bromonium ion, back attack by Br⁻ | Anti addition |
| E2 | One step, base removes β-H as X leaves | rate = k[RX][B]; anti-periplanar; no rearrangement |
| E1 | Slow ionisation to carbocation, then loss of β-H | rate = k[RX]; rearrangement possible |
| SN2 | One step, backside attack, pentacoordinate transition state | rate = k[RX][Nu]; inversion; CH3 > 1° > 2° > 3° |
| SN1 | Slow ionisation to planar carbocation, fast attack | rate = k[RX]; racemisation; 3° > 2° > 1° |
| Aldol | OH⁻ forms enolate → adds to C=O → protonation → (heat) dehydration | Needs α-H, dilute alkali |
| Cannizzaro | OH⁻ adds → hydride transfer to second aldehyde → proton exchange | No α-H, concentrated alkali |
| Benzoin | CN⁻ adds → carbanion → attacks second ArCHO → CN⁻ leaves | KCN catalyst, aromatic aldehydes |
| Perkin | Acetate makes anhydride carbanion → adds to ArCHO → elimination → hydrolysis | Gives cinnamic acid |
| Diels–Alder | Diene (s-cis) + dienophile in one concerted step | Gives cyclohexene; syn, stereospecific |

**Common traps in MCQs**

- The peroxide effect works **only with HBr**, not HCl or HI.
- SN2 gives **inversion**; SN1 gives **racemisation**; rearrangement only in SN1/E1.
- Aldehydes **with** α-H → aldol; **without** α-H → Cannizzaro. Formaldehyde, benzaldehyde and trimethylacetaldehyde have no α-H.
- In crossed Cannizzaro with HCHO, **formaldehyde is oxidised**, the other aldehyde is reduced.
- Benzaldehyde gives Tollens' test but usually **not** Fehling's test.
- Methanol gives a **negative** iodoform test; ethanol and propan-2-ol are positive.
- Benzyl alcohol is an alcohol, **not** a phenol (no FeCl3 colour).
- Amphetamine is a **primary** amine; amides are **not** basic.
- 2° aliphatic amines are the strongest bases in water, not 3°.
- Formic acid reduces Tollens' reagent; acetic acid does not.

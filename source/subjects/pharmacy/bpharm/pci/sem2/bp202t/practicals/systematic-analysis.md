# Systematic qualitative analysis of an unknown organic compound

**Aim:** To identify an unknown organic compound by systematic analysis — preliminary tests, element detection, solubility, functional group tests, melting or boiling point, comparison with literature values and confirmation by a derivative. (The syllabus asks for at least five unknowns to be analysed this way.)

> Quantities are typical for a student batch. Follow your lab manual and your teacher where they differ. Treat every unknown as toxic and flammable.

## Principle

No single test identifies an organic compound. Each step removes possibilities: preliminary tests suggest aromatic/aliphatic and saturated/unsaturated; Lassaigne's test shows which elements are present; solubility tells whether it is an acid, phenol, base, neutral or inert compound; functional group tests name the group; the melting or boiling point picks one compound from the literature list for that group; and a **solid derivative** with a sharp melting point confirms the identity.

```text
   Unknown
     │
     ├─ 1. Physical state, colour, odour, ignition, unsaturation
     ├─ 2. Lassaigne's test: N, S, halogens
     ├─ 3. Solubility: water → NaOH → NaHCO3 → HCl → conc. H2SO4
     ├─ 4. Functional group tests (choose by steps 2 and 3)
     ├─ 5. Melting point / boiling point
     ├─ 6. Match with literature values for that functional group
     └─ 7. Prepare a solid derivative, find its melting point, compare → confirm
```

## Requirements

All reagents of the preliminary, Lassaigne's, solubility and functional group practicals; melting/boiling point apparatus; reagents for derivatives; tables of melting points of compounds and derivatives.

## Procedure

1. Record the physical state, colour and odour, and perform the ignition and unsaturation tests.
2. Prepare Lassaigne's extract and test for N, S and halogens.
3. Carry out solubility tests in order.
4. Use the results to choose functional group tests:
   - No N, soluble in NaHCO3 → carboxylic acid tests.
   - No N, soluble in NaOH only → phenol tests.
   - N present, soluble in dilute HCl → amine tests.
   - N present, neutral → amide, urea, anilide or nitro tests.
   - Neutral, no N, soluble in conc. H2SO4 → carbonyl, alcohol, ester tests.
   - Neutral, sweet, chars → carbohydrate tests.
   - Inert → aromatic hydrocarbon or halide tests.
5. Determine the melting point (solid) or boiling point (liquid).
6. Short-list compounds of that functional group whose literature value is within about 2–3 °C of yours.
7. Prepare a suitable solid derivative (see the solid derivatives practical), purify it and find its melting point; the compound whose derivative matches is the answer.

## Observations and inference (worked example)

| Experiment | Observation | Inference |
| --- | --- | --- |
| State, colour, odour | White crystalline solid, odourless | — |
| Ignition | Sooty flame, no residue | Aromatic, not a salt |
| Bromine in CCl4 | No decolourisation | No C=C in side chain |
| Lassaigne's test | No N, S or halogen | Contains C, H, (O) only |
| Water | Sparingly soluble in cold, soluble in hot | Polar, small aromatic |
| 5% NaHCO3 | Dissolves with brisk effervescence | Carboxylic acid |
| Ester test | Fruity odour | Carboxylic acid confirmed |
| Neutral FeCl3 | Buff precipitate | Benzoate |
| Melting point | 121–122 °C | Benzoic acid (lit. 122 °C) |
| Derivative: amide (via acid chloride + NH3) | Melting point 127–128 °C | Benzamide (lit. 128 °C) |

**Conclusion:** the unknown is **benzoic acid**, C6H5COOH.

## Precautions

1. Use a fresh portion of the unknown for each test; never return material to the stock bottle.
2. Always run the element test before deciding which group tests to do.
3. Dry and recrystallise the derivative before taking its melting point.
4. Report the melting point as a range, and compare with the literature value.

## Viva questions

1. **Why is a derivative prepared?** It confirms identity, because two compounds with similar melting points usually give derivatives with different melting points.
2. **What qualities should a good derivative have?** Easy and quick to prepare in good yield, a crystalline solid with a sharp melting point clearly different from those of other candidates.
3. **Why is Lassaigne's test done before the functional group tests?** It tells you which groups are possible (e.g. no amine tests if N is absent).
4. **How do you distinguish benzoic acid from salicylic acid?** FeCl3: buff precipitate vs violet colour; melting points 122 vs 158 °C.
5. **Why does a compound that dissolves in NaOH but not NaHCO3 suggest a phenol?** Phenols are weaker acids than carbonic acid.
6. **What is meant by literature value?** The accepted melting or boiling point recorded in standard reference tables.

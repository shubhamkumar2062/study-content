# Last-night revision sheet

If you only have an hour, learn these five answers in full, each with its diagram: **deforestation (causes, effects, conservation)**, **structure and function of an ecosystem with energy flow and pyramids**, **nitrogen cycle**, **air pollution (sources, effects, control devices)** and **water pollution with eutrophication and sewage treatment**. Together they cover most 10-mark questions.

## Unit 1 — Environmental studies and natural resources

| Point | Key fact |
| --- | --- |
| Environment | All living and non-living surroundings; lithosphere, hydrosphere, atmosphere, biosphere |
| Multidisciplinary | Biology, chemistry, physics, geology, engineering, economics, law, sociology, medicine |
| Sustainable development | Meet today's needs without reducing future generations' ability to meet theirs |
| Renewable resources | Forests, water, food, soil, solar, wind |
| Non-renewable resources | Coal, petroleum, natural gas, minerals, uranium |
| Forest uses | Timber, fuel, medicinal plants, gums, resins; protect soil, water and climate |
| Deforestation effects | Erosion, floods, biodiversity loss, global warming, tribal livelihood loss |
| Forest target in India | One-third of land area (National Forest Policy 1988) |
| Earth's water | About 97% salt; small part fresh, most of that in ice |
| Groundwater overuse | Falling water table, subsidence, salt-water intrusion |
| Dams | Irrigation, power, flood control vs displacement, submergence, silting, water logging |
| Mining effects | Land scars, dust, acid mine drainage, silicosis, subsidence |
| Modern agriculture | Fertilisers → eutrophication, nitrate in water; pesticides → resistance, biomagnification; over-irrigation → water logging and salinity |
| Alternative energy | Solar, wind, hydro, biogas, geothermal, tidal, hydrogen |
| Land degradation | Soil erosion, landslides, desertification, salinity |
| Erosion control | Afforestation, contour ploughing, terracing, strip cropping, windbreaks |
| Individual role | Save water and power, 3 Rs, plant trees, return unused medicines |

## Unit 2 — Ecosystems

```text
Structure: abiotic (inorganic, organic, climatic) + biotic (producers, consumers, decomposers)
Function:  energy flow · nutrient cycling · productivity · succession

Sun → producers → herbivores → carnivores → top carnivores   (about 10% passes on each step)
```

| Point | Key fact |
| --- | --- |
| Ecosystem term | Tansley, 1935 |
| GPP / NPP | Total photosynthesis / GPP minus plant respiration |
| Energy flow | One-way; nutrients cycle |
| Food chains | Grazing (starts with green plants), detritus (starts with dead matter) |
| Food web | Interlinked chains; gives stability |
| Pyramid of energy | Always upright |
| Pyramid of numbers | Upright in grassland; spindle in tree chain; inverted in parasite chain |
| Pyramid of biomass | Inverted in pond and ocean |
| Nitrogen cycle | Fixation (*Rhizobium*, *Azotobacter*, lightning) → assimilation → ammonification → nitrification (*Nitrosomonas*, *Nitrobacter*) → denitrification |
| Biomagnification | Non-degradable, fat-soluble pollutants rise up the chain (DDT, mercury) |
| Succession | Pioneer → seral stages → climax; primary (bare rock) vs secondary (abandoned field) |
| Forest types | Tropical evergreen, deciduous, thorn, temperate coniferous, mangrove |
| Desert | Rainfall below about 25 cm a year; xerophytes; Thar (hot), Ladakh (cold) |
| Lake zones | Littoral, limnetic, profundal, benthic |
| Estuary | River meets sea; brackish; very productive; Sundarbans |

## Unit 3 — Pollution

| Pollutant | Source | Effect |
| --- | --- | --- |
| CO | Vehicle exhaust | Carboxyhaemoglobin, less oxygen to tissues |
| SO2, NOx | Coal, vehicles | Respiratory irritation, acid rain |
| PM2.5 | Dust, smoke, stubble burning | Deep lung damage, heart disease |
| Ozone, PAN | Photochemical smog | Eye and lung irritation, crop damage |
| Lead | Smelters, batteries, old leaded petrol | Nerve damage in children |
| CFCs | Old refrigerants, aerosols | Ozone depletion |
| CO2, CH4, N2O | Fuels, farming | Global warming |

| Topic | Remember |
| --- | --- |
| Smog | Classical: smoke + SO2, cold fog; photochemical: NOx + hydrocarbons + sunlight |
| Acid rain | SO2 → H2SO4, NOx → HNO3; normal rain about pH 5.6 |
| Ozone depletion | Cl· chain reaction; Antarctic hole; Montreal Protocol 1987 |
| Particle control | Settling chamber, cyclone, bag filter, ESP, wet scrubber |
| Gas control | Absorption, adsorption (activated carbon), incineration, catalytic converter |
| DO / BOD / COD | DO high = clean; BOD 5 days at 20 °C; COD by dichromate; COD ≥ BOD |
| Eutrophication | Nutrients → algal bloom → oxygen loss → fish death |
| Heavy metal diseases | Minamata = mercury; itai-itai = cadmium; blue baby = nitrate; fluorosis = fluoride |
| Sewage treatment | Preliminary → primary → secondary (activated sludge, trickling filter) → tertiary → disinfection |
| Soil pollution control | 3 Rs, segregation, composting, sanitary landfill, incineration, bioremediation |
| Biomedical waste | Segregate at source into colour-coded containers; Bio-Medical Waste Management Rules 2016 |
| Laws | Water Act 1974, Air Act 1981, Environment (Protection) Act 1986 |
| Disaster example | Bhopal 1984, methyl isocyanate |

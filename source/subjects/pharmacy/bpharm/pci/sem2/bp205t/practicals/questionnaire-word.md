# Questionnaire on a disease using a word processor

**Aim:** To design a questionnaire using a word-processing package (MS Word) to gather information from patients about a particular disease (example: type 2 diabetes mellitus).

> Menu names are for a recent version of Microsoft Word. Older versions or other word processors (LibreOffice Writer, Google Docs) have the same tools under slightly different names.

## Principle

A **questionnaire** is a written set of questions given to many people to collect information in a uniform way. A word processor lets you type, format and arrange text and add tables, check boxes and drop-down lists, so the questionnaire is neat, easy to fill and easy to change. Good questionnaires use short, clear, unbiased questions in a logical order, a mix of closed questions (yes/no, multiple choice, rating scales) that are easy to count and a few open questions for comments.

## Requirements

Computer with MS Word, printer, a topic (disease) and a list of the information to be collected.

## Procedure

1. Open MS Word → **Blank document**. Set the page: **Layout → Margins → Normal**, **Size → A4**.
2. Type a title, e.g. *"Patient Questionnaire: Type 2 Diabetes Mellitus"*. Select it, choose **Home → Styles → Title** (or bold, 16 pt, centred).
3. Add a short introduction: purpose of the survey, that answers are confidential, and the institution's name.
4. **Section A — Patient details.** Insert a table (**Insert → Table → 2 × 6**) with rows: Name/ID, Age, Gender, Weight, Height, Occupation.
5. **Section B — Disease history.** Type closed questions such as *"How long have you had diabetes? □ < 1 year □ 1–5 years □ > 5 years"*. Insert box symbols with **Insert → Symbol** (Wingdings box) or use **Developer → Check Box Content Control** (enable the Developer tab from **File → Options → Customize Ribbon**).
6. **Section C — Medicines and adherence.** Questions on medicines taken, missed doses per week, side effects noticed, blood glucose monitoring at home.
7. **Section D — Lifestyle.** Diet, exercise, smoking, alcohol, using a rating scale table (Never / Sometimes / Often / Always).
8. **Section E — Open comments.** *"Any problem you face with your treatment?"* with blank lines.
9. Number the questions with **Home → Numbering**. Use headings for each section so the order is clear.
10. Add a header (institution name) and footer with page numbers: **Insert → Header / Page Number**.
11. Check spelling (**Review → Spelling & Grammar**) and preview (**File → Print**). Save as `Diabetes_Questionnaire.docx`; optionally save a PDF copy (**File → Save As → PDF**).
12. Print and give the questionnaire to a few volunteers as a pilot test; correct unclear questions.

## Precautions

1. Keep questions short, clear and free from leading words ("Don't you agree…").
2. Ask one thing per question; give all reasonable answer choices including "Other".
3. Keep personal details confidential; ask for consent.
4. Save the file frequently and keep a backup.
5. Pilot test before final printing.

## Viva questions

1. **What is a word processor?** Software for typing, editing, formatting and printing documents, e.g. MS Word.
2. **Closed vs open questions?** Closed questions offer fixed choices and are easy to count; open questions let people answer in their own words.
3. **How do you insert a table?** Insert → Table, then choose rows and columns.
4. **What is a header and footer?** Text repeated at the top and bottom of every page, such as the title and page number.
5. **How do you save a Word file as PDF?** File → Save As (or Export) → choose PDF.
6. **Why pilot test a questionnaire?** To find unclear or missing questions before the real survey.

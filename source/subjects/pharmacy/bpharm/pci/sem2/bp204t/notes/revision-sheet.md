# Last-night revision sheet

If you only have an hour, learn these five topics with a flow diagram each: **mechanism of inflammation with mediators**, **cell injury (causes, mechanism, adaptations, necrosis vs apoptosis)**, **hypertension or congestive heart failure**, **diabetes mellitus**, and **tuberculosis**. Then revise the comparison tables below — they cover most short questions.

**Unit 1 in ten lines**

- Homeostasis = negative feedback (temperature, BP, glucose); positive feedback = labour, clotting.
- Cell injury: hypoxia is the commonest cause → ATP loss → Na⁺ pump fails → swelling → Ca²⁺ influx, free radicals, membrane damage → necrosis.
- Atrophy ↓ size · hypertrophy ↑ size · hyperplasia ↑ number · metaplasia = cell type change · dysplasia = disordered, pre-cancerous.
- Necrosis types: coagulative (heart), liquefactive (brain, abscess), caseous (TB), fat (pancreas), fibrinoid, gangrene.
- Apoptosis: shrinkage, caspases, no inflammation.
- Dystrophic calcification = dead tissue, normal Ca; metastatic = normal tissue, high Ca.
- Inflammation signs: rubor, calor, tumor, dolor, functio laesa.
- WBC: margination → rolling (selectins) → adhesion (integrins/ICAM-1) → diapedesis → chemotaxis → phagocytosis.
- Wound healing: haemostasis → inflammation → proliferation (granulation tissue) → remodelling.
- Atherosclerosis: endothelial injury → oxidised LDL → foam cells → fatty streak → fibrous plaque → rupture → thrombus.

**Must-know comparisons**

| Pair | One-line difference |
| --- | --- |
| Acute vs chronic inflammation | Neutrophils, fast, little fibrosis vs macrophages/lymphocytes, slow, fibrosis |
| Exudate vs transudate | Protein-rich, SG > 1.020 vs protein-poor, SG < 1.012 |
| Primary vs secondary intention | Clean, close edges, thin scar vs gaping wound, granulation, contraction |
| Left vs right heart failure | Lungs (dyspnoea, orthopnoea, crackles) vs body veins (oedema, JVP, liver) |
| Stable vs unstable vs Prinzmetal angina | Exertion vs rest (plaque rupture) vs spasm |
| Asthma vs COPD | Young, IgE, eosinophils, reversible vs smoker, neutrophils, poorly reversible |
| Chronic bronchitis vs emphysema | Productive cough 3 months × 2 years vs alveolar wall destruction |
| Acute vs chronic renal failure | Sudden, reversible vs slow, irreversible, anaemia, bone disease |
| B12 vs folate deficiency | Nerve damage, pernicious anaemia vs no nerve damage, pregnancy, drugs |
| Haemophilia A vs B | Factor VIII vs factor IX (both X-linked recessive) |
| Type 1 vs type 2 diabetes | Autoimmune, thin, ketoacidosis, insulin vs insulin resistance, obese, oral drugs |
| Hyper- vs hypothyroidism | Weight loss, heat intolerance, tachycardia vs weight gain, cold intolerance, bradycardia |
| Gastric vs duodenal ulcer | Pain after food, weight loss vs pain relieved by food, night pain |
| Crohn's vs UC | Skip, transmural, granulomas, fistulae vs continuous from rectum, mucosal, bloody diarrhoea |
| Jaundice types | Haemolytic (unconjugated) · hepatocellular (both) · obstructive (conjugated, pale stools, itch) |
| RA vs osteoarthritis | Autoimmune, small joints, symmetrical, long morning stiffness vs wear-and-tear, weight-bearing joints |
| Benign vs malignant | Capsule, no invasion or metastasis vs invasion, metastasis, anaplasia |
| Tuberculoid vs lepromatous leprosy | Good immunity, few bacilli, few anaesthetic patches vs poor immunity, many bacilli, leonine face |
| Primary vs secondary TB | Ghon complex, children vs apical cavity, reactivation in adults |

**Key mechanisms in one line**

| Disease | Core mechanism |
| --- | --- |
| Hypertension | ↑ CO × ↑ TPR via RAAS, sympathetic activity, Na⁺ retention |
| Heart failure | ↓ output → SNS + RAAS + ADH + remodelling (help, then harm) |
| MI | Plaque rupture → occlusive thrombus → necrosis after ~20–40 min |
| Asthma | Th2 → IgE → mast cells → early (histamine, LTs) and late (eosinophils) phase |
| Emphysema | Protease (elastase) > antiprotease (α1-antitrypsin) |
| Sickle cell | Glu → Val at β6 → HbS polymerises at low O2 |
| Parkinson's | Loss of nigrostriatal dopamine neurons, Lewy bodies (α-synuclein) |
| Alzheimer's | β-amyloid plaques + tau tangles + ACh loss |
| Schizophrenia | Mesolimbic dopamine excess (positive symptoms) |
| Depression | Monoamine (NA, 5-HT) deficit, HPA overactivity |
| Peptic ulcer | H. pylori and NSAIDs tip acid/pepsin over mucosal defence |
| Gout | Urate crystals → IL-1β inflammation; podagra |
| Cancer | Oncogenes on (RAS, MYC) + suppressors off (p53, RB) + no apoptosis |
| HIV | gp120 + CD4 + CCR5/CXCR4 → reverse transcriptase → CD4 loss |

**Organisms in one line**: TB — *M. tuberculosis*; leprosy — *M. leprae*; typhoid — *Salmonella* Typhi; UTI — *E. coli*; meningitis — pneumococcus, meningococcus, Hib; syphilis — *Treponema pallidum*; gonorrhoea — *Neisseria gonorrhoeae*; AIDS — HIV (retrovirus); peptic ulcer and gastric cancer — *Helicobacter pylori*; cervical cancer — HPV.

# Last-night revision sheet

If you have only an hour, learn these five answers well: **unit dose drug distribution**, **PTC (composition, functions, automatic stop order, emergency drug list)**, **classification and reporting of ADRs**, **clinical pharmacy and pharmaceutical care**, and **inventory control with EOQ and ABC/VED analysis**. Together they cover most 10-mark questions.

## Unit 1 – Hospital, hospital pharmacy, ADRs, community pharmacy

| Item | Key point |
| --- | --- |
| Hospital levels | Primary (sub-centre, PHC) → secondary (CHC, district) → tertiary (medical college, super-speciality) |
| Clinical basis | General vs speciality (TB, cancer, maternity, mental, eye) |
| Non-clinical basis | Ownership, teaching/non-teaching, length of stay, size, system of medicine |
| Hospital pharmacy location | Ground floor, near OPD and emergency, links to wards, vehicle access |
| Layout | OPD and IP dispensing, bulk store, cold store, controlled drug store, flammable store, manufacturing, DIC, office |
| ADR (WHO) | Noxious, unintended, at normal doses |
| ADR types (syllabus) | Excessive effect, secondary effect, idiosyncrasy, allergy, genetic, withdrawal |
| Rawlins–Thompson | A augmented, B bizarre, C chronic, D delayed, E end of use, F failure |
| Detection | Spontaneous reports (cheap, under-reported), intensive monitoring, cohort, case–control, **record linkage** |
| India | **PvPI 2010**, NCC = IPC Ghaziabad, AMCs, helpline **1800-180-3024** |
| Causality | WHO–UMC; **Naranjo ≥9 definite, 5–8 probable, 1–4 possible, ≤0 doubtful** |
| Interactions | Pharmacokinetic (ADME), pharmacodynamic, pharmaceutical; beneficial (probenecid + penicillin, carbidopa + levodopa) |
| Drug store licences | Retail **20/21**, wholesale **20B/21B**, restricted **20A/21A**, Schedule X **20F/20G** |
| Premises | **10 m²**; 15 m² if retail + wholesale; refrigerator; registered pharmacist |
| Records | H1 register **3 years**; Schedule X **2 years** |

## Unit 2 – Distribution, formulary, TDM, adherence

| Item | Key point |
| --- | --- |
| Distribution systems | Individual prescription, floor stock (charged / non-charged), combination, **unit dose**, automated |
| UDDS | Single unit, ready to give, **≤24 h supply**, patient drawer, credit for returns, fewest errors |
| Controlled drugs | Double lock, written signed order, register, return empty ampoules |
| Formulary | Policies + drug list + special information; by PTC; revised regularly |
| Formulary vs drug list | Formulary has information and policy; drug list only names |
| TDM need | Narrow therapeutic index, variable kinetics, non-linear kinetics, toxicity or non-adherence suspected |
| TDM drugs | Digoxin, phenytoin, carbamazepine, valproate, lithium, aminoglycosides, vancomycin, theophylline, cyclosporine |
| TDM sampling | Steady state (**4–5 half-lives**), usually trough |
| Non-adherence | WHO dimensions: patient, condition, therapy, health system, socio-economic |
| Monitoring adherence | Self-report, Morisky scale, pill count, refill records, electronic caps, drug levels, DOT |
| Medication history | All Rx, OTC, herbal, allergies, habits; verify sources; reconciliation |
| Community pharmacy management | Finance, materials, staff, infrastructure |

## Unit 3 – PTC, DIC, counselling, ethics, prescription

| Item | Key point |
| --- | --- |
| PTC | Advisory link between medical staff and pharmacy; chairman physician, **secretary chief pharmacist** |
| PTC policies | Formulary inclusion, IP/OP prescriptions, **automatic stop order**, **emergency drug list** |
| ASO | Narcotics, antimicrobials, anticoagulants, steroids stopped after a set time unless re-ordered |
| DI sources | **Primary** journals; **secondary** PubMed, Embase, IPA; **tertiary** Martindale, IP, NFI, BNF, AHFS, CIMS |
| Query steps | Demographics → background → real question → search → evaluate → respond → follow-up and document |
| National Poisons Information Centre | AIIMS, New Delhi |
| Counselling steps | Preparation → opening → content → process (teach-back) → closing → documentation |
| Three prime questions | What is it for? How to take it? What to expect? |
| Code of ethics | Pharmacist in relation to job, trade, medical profession, profession, public |
| Prescription | Superscription (Rx), inscription, subscription, signatura; RMP signature, date, patient name and address |
| Communication | Sender, message, channel, receiver, feedback; active listening; SBAR-style with prescribers |

## Unit 4 – Budget, clinical pharmacy, OTC

| Item | Key point |
| --- | --- |
| Budget types | Operating (revenue), capital, personnel, cash |
| Approaches | Incremental vs **zero-based** |
| Steps | Past data → forecast → estimate → draft → approve → implement → variance → revise |
| Clinical pharmacy | Patient-focused; Pharm.D in India from **2008** |
| Drug therapy monitoring | Chart review, clinical review, interventions, ward rounds, medication history |
| Pharmaceutical care | **Hepler and Strand 1990** – responsible drug therapy for definite outcomes improving quality of life |
| Renal dosing | **Cockcroft–Gault**: CrCl = (140 − age) × weight / (72 × SCr), ×0.85 women; reduce dose or extend interval |
| Elderly | Start low, go slow; Beers criteria |
| OTC in India | No legal category; drugs outside Schedules H, H1, X |
| WWHAM | Who, What symptoms, How long, Action taken, Medicines taken |
| Rational OTC | ORS first in diarrhoea; no antibiotics for colds; watch hidden paracetamol; refer red flags |

## Unit 5 – Stores, inventory, investigational drugs, lab tests

| Item | Key point |
| --- | --- |
| Storage | Cold **2–8 °C**, cool **8–25 °C**, FEFO, separate controlled and flammable stores |
| Purchase methods | Open, limited, single tender, negotiated, rate contract, centralised |
| Purchase order | Number, date, supplier, items, quantity, price, delivery, shelf life, signature |
| **EOQ** | √(2AO/C); A annual demand, O ordering cost, C carrying cost per unit per year |
| Reorder level | Max usage × max lead time (or average usage × lead time + safety stock) |
| ABC | Value: A ≈ 10–20% items, 70–80% money |
| VED | Vital, essential, desirable (criticality) |
| Others | FSN movement, SDE availability, HML unit price, ABC–VED matrix |
| Investigational drugs | NDCT Rules 2019, ethics committee, consent, GCP, trial labels, accountability, return to sponsor |
| Phases | I safety/PK, II efficacy/dose, III confirm, IV post-marketing |
| Lab values (approx.) | Na 135–145, K 3.5–5.0 mEq/L; creatinine 0.6–1.2 mg/dL; fasting glucose ≥126 = diabetes; HbA1c ≥6.5% |
| Haematology | Hb men 13–17, women 12–15 g/dL; WBC 4,000–11,000/µL; platelets 1.5–4.5 lakh/µL; MCV 80–100 fL |
| Urine | SG 1.005–1.030; no protein, glucose, ketones, blood; nitrite + = UTI |

## Formula to write in the exam

```text
 EOQ = √(2 × A × O / C)
 Example: A = 4000, O = ₹200, C = ₹4 → EOQ = √400000 ≈ 632 units
 ROL = (average daily use × lead time in days) + safety stock
```

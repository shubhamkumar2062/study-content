# Last-night revision sheet

If you only have an hour, learn these with full block diagrams: **UV-visible spectrophotometer (with Beer–Lambert law and deviations)**, **fluorimetry (Jablonski diagram, factors, quenching)**, **IR (modes of vibration, sample handling, detectors)**, **AAS vs flame photometry**, **TLC**, **GC with detectors**, **HPLC instrumentation** and **ion exchange resins**. Together they cover most 10-mark questions.

**Block diagrams in one line each**

- UV-vis: source → monochromator → sample cell → detector → readout.
- Fluorimeter: source → excitation filter → cell → (90°) emission filter → PMT.
- IR: source → sample/reference → chopper → monochromator → thermal detector.
- Flame photometer: nebuliser → burner/flame → filter → detector.
- AAS: hollow cathode lamp → chopper → flame or furnace → monochromator → PMT.
- GC: carrier gas → regulator → heated injector → column in oven → detector → data.
- HPLC: reservoir → degasser → pump → loop injector → guard + column → detector → data.

**Last-minute traps**

- Fluorescence is measured at 90°, absorption in line.
- Flame photometry measures emission; AAS measures absorption by ground-state atoms.
- In gel chromatography the **largest** molecules come out **first**.
- In reversed-phase HPLC the most **polar** compound elutes **first**.
- CO2 symmetric stretch is IR inactive.
- Paper chromatography is mainly partition; TLC on silica is mainly adsorption.

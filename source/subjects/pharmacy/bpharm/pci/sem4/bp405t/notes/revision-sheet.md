# Last-night revision sheet

If you only have an hour, learn these five topics fully: **classification of crude drugs with examples**, **evaluation of crude drugs including leaf constants and the lycopodium method**, **plant tissue culture (types, medium, applications)**, **definition, classification and tests of alkaloids and glycosides**, and **monographs of acacia, tragacanth, agar, honey, castor oil and beeswax**. Together they cover most 10-mark questions.

**Unit 1 in one table**

| Topic | Key points |
| --- | --- |
| Pharmacognosy | *pharmakon* + *gnosis*; Seydler, 1815 |
| Organised drugs | Have cells: leaves, barks, roots, flowers, fruits, seeds |
| Unorganised drugs | No cells: latex (opium), juice (aloe), extract (catechu), gums, resins, balsams, waxes |
| Classifications | Alphabetical, morphological, taxonomical, chemical, pharmacological, chemotaxonomic, serotaxonomic |
| Evaluation | Organoleptic, microscopic, physical, chemical, biological |
| Stomata | Anomocytic (digitalis), anisocytic (belladonna), diacytic (vasaka), paracytic (senna) |
| Stomatal index | SI = S × 100/(E + S) |
| Lycopodium | ~94,000 spores/mg; particles/mg = N × W × 94,000/(S × M) |
| Ash values | Total, acid-insoluble (sand, silica), water-soluble, sulphated |

**Last-minute traps**

- Bassorin swells but does not dissolve; tragacanthin dissolves.
- Castor oil is miscible with alcohol; chaulmoogra oil is dextrorotatory.
- Wool fat and beeswax are waxes, not fats (no glycerol).
- Streptokinase is not an enzyme itself; urokinase activates plasminogen directly.
- Acid-insoluble ash shows sand and earth; very low water-soluble ash suggests an exhausted drug.

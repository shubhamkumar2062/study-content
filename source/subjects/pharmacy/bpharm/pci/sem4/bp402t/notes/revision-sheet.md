# Last-night revision sheet

If you have only an hour, learn these five with full skeletons: **SAR of sympathomimetics**, **SAR of beta blockers**, **SAR of parasympathomimetics and anticholinergics**, **SAR of benzodiazepines, barbiturates and phenothiazines**, and **phase I / phase II metabolism**. Then read the synthesis table below twice.

## The five skeletons to draw from memory

```text
1. Sympathomimetic      Ar(3,4-OH) — CH(OH) — CH(R') — NH — R
                        N-substituent: H→α, CH3→α+β, iPr→β, t-Bu→β2

2. Beta blocker         Ar — O — CH2 — CH(OH) — CH2 — NH — iPr
                        para substituent on benzene → β1 selective; naphthalene → propranolol

3. Acetylcholine        CH3CO — O — CH2CH2 — N+(CH3)3   (five-atom rule)
                        carbamate → resists AChE; β-methyl → muscarinic selectivity

4. Anticholinergic      (Ar)(Ar or cyclohexyl)(OH)C — CO — O — CH2CH2 — N(R)2
                        tertiary → central; quaternary → peripheral only

5. Morphine "T"         aromatic ring + quaternary carbon + 2-carbon bridge + basic N
                        N-CH3 → agonist; N-allyl / N-cyclopropylmethyl → antagonist
```

## Pathways worth writing in full

```text
Tyrosine → DOPA → Dopamine → Noradrenaline → Adrenaline
  (tyrosine hydroxylase = rate-limiting; PNMT only in adrenal medulla)
Breakdown: uptake-1, MAO and COMT → VMA in urine

Choline + Acetyl-CoA → Acetylcholine (ChAT)
Acetylcholine → Choline + Acetic acid (AChE: anionic + esteratic site)
```

## One-line contrasts examiners like

| Pair | Difference |
| --- | --- |
| Phase I vs phase II | Phase I adds or exposes a polar group; phase II attaches a polar partner (acetylation and methylation do not raise solubility) |
| Enzyme induction vs inhibition | Induction (phenobarbitone, rifampicin) is slow in and slow out; inhibition (cimetidine, ketoconazole) is immediate |
| AChE vs pseudocholinesterase | True enzyme at the synapse, specific for ACh; plasma enzyme hydrolyses succinylcholine and esters |
| Carbamate vs organophosphate | Carbamoylated enzyme recovers in hours; phosphorylated enzyme does not, and can age |
| Benzodiazepine vs barbiturate | Frequency vs duration of chloride channel opening; benzodiazepine needs GABA, so overdose is safer |
| Tertiary vs quaternary anticholinergic | Atropine (central, oral) vs ipratropium (peripheral, inhaled) |
| Typical vs atypical antipsychotic | D2 blockade with extrapyramidal effects vs added 5-HT2A blockade with fewer movement effects |
| Hydantoin vs succinimide | Aryl substituent → tonic-clonic (phenytoin); small alkyl → absence (ethosuximide) |
| MAC vs blood : gas coefficient | Potency vs speed of induction and recovery |
| Aspirin vs other NSAIDs | Irreversible acetylation of COX vs reversible competition |
| Morphine vs codeine | Free 3-OH vs 3-methyl ether; codeine is a prodrug demethylated by CYP2D6 |

## Numbers and facts worth memorising

| Fact | Value |
| --- | --- |
| Best log P for CNS activity | about 2 |
| Barbiturate C5 substituents, total carbons | about 6–10 |
| Benzodiazepine: essential substituent | electron-withdrawing group at position 7 |
| Phenothiazine side chain | exactly 3 carbons at N10 (2 carbons = antihistamine) |
| Potency order at beta receptors | isoprenaline > adrenaline > noradrenaline |
| Fentanyl potency vs morphine | about 80–100 times |
| Aspirin antiplatelet effect | lasts the platelet lifetime, 7–10 days |
| Final urinary metabolite of catecholamines | vanillylmandelic acid (VMA) |
| Organophosphate poisoning treatment | atropine plus pralidoxime (before ageing) |
| Paracetamol overdose antidote | N-acetylcysteine (replaces glutathione) |

## Named reactions used in this subject

Benzoin condensation and benzilic acid rearrangement (phenytoin) · Knoevenagel (ethosuximide) · Mannich (procyclidine) · Grignard (procyclidine, ketamine, methadone) · Friedel–Crafts acylation (salbutamol, ibuprofen) · Darzens glycidic ester (ibuprofen) · Ullmann condensation (mefenamic acid) · Pinner imino ether (tolazoline) · von Braun demethylation (ipratropium).

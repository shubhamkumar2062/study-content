# Last-night revision sheet

If you only have an hour, learn these five topics with a classification table and a diagram each: **drug metabolism with enzyme induction and inhibition**, **receptor types and G-protein signalling with the dose–response curve**, **organophosphate poisoning with cholinergic and anticholinergic drugs**, **antiepileptic drugs**, and **morphine with opioid poisoning**. Together they cover most 10-mark questions.

**Key definitions in one line**

| Term | One line |
| --- | --- |
| Pharmacokinetics / pharmacodynamics | Body on drug (ADME) / drug on body (action, mechanism) |
| Bioavailability | Fraction of dose reaching systemic circulation unchanged = AUC oral / AUC IV |
| First-pass metabolism | Loss in gut wall and liver before systemic circulation (GTN, lignocaine, propranolol, morphine) |
| Volume of distribution | Amount in body ÷ plasma concentration |
| Half-life | Time for plasma level to halve; t½ = 0.693 Vd/CL; steady state after 4–5 t½ |
| Therapeutic index | LD50/ED50; narrow in digoxin, lithium, phenytoin, theophylline, warfarin |
| Potency vs efficacy | Dose needed (curve position) vs maximum effect (curve height) |
| Tachyphylaxis | Rapid tolerance, not overcome by more drug (ephedrine, tyramine) |
| Idiosyncrasy | Genetic abnormal response (primaquine in G6PD deficiency) |
| ADR | Noxious, unintended response at normal doses |
| Pharmacovigilance | Detection, assessment, understanding and prevention of ADRs (PvPI, IPC Ghaziabad) |

**Contrasts examiners like**

| Pair | Difference |
| --- | --- |
| Competitive vs non-competitive antagonist | Parallel right shift, same max vs max reduced |
| First vs zero order | Constant fraction vs constant amount per time (alcohol, high-dose phenytoin) |
| Phase I vs phase II | Add polar group (CYP450 oxidation) vs conjugation (glucuronide most common) |
| Enzyme inducers vs inhibitors | Phenobarbitone, phenytoin, carbamazepine, rifampicin vs cimetidine, erythromycin, ketoconazole, ciprofloxacin, valproate |
| Gs / Gi / Gq | ↑cAMP (β) / ↓cAMP (α2, M2) / IP3 + DAG (α1, M1, M3) |
| Depolarising vs non-depolarising blocker | Succinylcholine (fasciculations, neostigmine worsens) vs d-tubocurarine (neostigmine reverses) |
| Ester vs amide LA | Procaine (plasma esterase, allergy) vs lignocaine (liver, longer) |
| BZD vs barbiturate | ↑ frequency vs ↑ duration of Cl− opening; flumazenil vs no antidote |
| Typical vs atypical antipsychotic | D2 block, more EPS vs D2 + 5-HT2A, less EPS, more weight gain |
| Psychological vs physical dependence | Craving vs withdrawal syndrome |

**Drugs of choice and antidotes**

| Situation | Drug |
| --- | --- |
| Anaphylactic shock | Adrenaline IM (1 in 1000) |
| Organophosphate poisoning | Atropine + pralidoxime |
| Atropine (anticholinergic) poisoning | Physostigmine (severe cases) |
| Benzodiazepine overdose | Flumazenil |
| Opioid overdose | Naloxone |
| Methanol poisoning | Ethanol or fomepizole, sodium bicarbonate, dialysis |
| Paracetamol overdose | N-acetylcysteine |
| Heparin overdose | Protamine sulfate |
| Malignant hyperthermia | Dantrolene |
| Absence seizures | Ethosuximide (or valproate) |
| Focal seizures, trigeminal neuralgia | Carbamazepine |
| Status epilepticus | IV lorazepam or diazepam |
| Myasthenia gravis | Pyridostigmine / neostigmine; edrophonium for diagnosis |
| Drug-induced parkinsonism | Central anticholinergic (trihexyphenidyl) |
| Parkinson's disease | Levodopa + carbidopa |
| Bipolar disorder (prophylaxis) | Lithium (monitor levels) |

**Classic adverse effects**

| Drug | Effect |
| --- | --- |
| Chloramphenicol (newborn) | Grey baby syndrome |
| Succinylcholine | Fasciculations, hyperkalaemia, apnoea with atypical pseudocholinesterase |
| Halothane | Hepatitis, arrhythmia with adrenaline |
| Nitrous oxide (prolonged) | Megaloblastic anaemia |
| Thiopentone | Laryngospasm; porphyria |
| Phenytoin | Gum hypertrophy, hirsutism, fetal hydantoin syndrome |
| Valproate | Neural tube defects, hepatotoxicity |
| Carbamazepine | Hyponatraemia, Stevens–Johnson syndrome |
| Clozapine | Agranulocytosis |
| Haloperidol | Extrapyramidal symptoms |
| MAOIs | Cheese reaction (tyramine) |
| Lithium | Tremor, hypothyroidism, diabetes insipidus |
| Morphine | Respiratory depression, constipation, miosis |
| Prazosin | First-dose hypotension |
| β-blockers | Bronchospasm, masked hypoglycaemia |

**Pathways to draw from memory**

```text
Catecholamines: Tyrosine → L-DOPA → Dopamine → Noradrenaline → Adrenaline
Acetylcholine:  Choline + Acetyl-CoA → ACh → (AChE) → Choline + Acetate
GABA:           Glutamate → (GAD) → GABA
Ethanol:        Ethanol → (ADH) → Acetaldehyde → (ALDH; blocked by disulfiram) → Acetic acid
Methanol:       Methanol → Formaldehyde → Formic acid (acidosis, blindness)
```

**Phases of clinical trials:** 0 microdose · I healthy volunteers, safety · II patients, efficacy and dose · III large randomised, confirm · IV post-marketing surveillance.
